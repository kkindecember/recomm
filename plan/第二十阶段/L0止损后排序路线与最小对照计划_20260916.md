## 1. 决策与依据

**停止当前内部KL路线扩展，暂停完整L1、Beauty蒸馏和lr/权重网格。将后续预算优先放回B1＋PCRF排序器。**

这不是证明任何内部迁移都不可行；是当前时间预算下不再为这条弱信号付出完整训练与fresh beam成本。L0只有32步，不能写成充分收敛失败。原R0/R1/R2不自动接替为新矩阵。

## 2. 下一项只选H0：同缓存、同预算的原目标继续训练

选择原因：已有B1相对B0的收益同时包含额外训练、optimizer重置、固定50项拟合、标准化和pairwise目标等变化。蒸馏现已止损，补一个小排序器对照可以以很低的计算成本确定应保留的训练版本，并避免将所有增益误归给新目标。它是确定有效方案和解释的实验，不保证比B1继续提点，也不将它作为无期限研究检查的起点。

| 项目 | H0方案 |
|---|---|
| 新增任务 | Toys、Beauty各1个seed2023小排序器训练；两域都做，不由Toys结果筛掉Beauty |
| 对照 | 既有同域同初始化B0和B1；重新前向核对参考分数/排名，复用已验证指标 |
| 起点 | 各域原v6 residual_seed2023，从与B1相同的B0权重开始，**不从B1续训** |
| 训练数据 | 既有train-only缓存、原fit/calibration划分、固定C1 50项；不插入候选外目标 |
| 模型与预算 | 原129参数6→16→1有界MLP；30次全量fit更新，head/tail各半；AdamW lr0.01、weight_decay0.01、clip10；128条仅是累积块 |
| H0目标 | 原v6的raw `g=1/rank+residual`上target-vs-hardest-negative hinge，margin0.1；其余训练要素与B1匹配 |

| 固定模型选择 | 第30步；calibration仅检查，禁止按中途validation挑checkpoint |
| 最终评估 | 两域完整既有validation缓存，H0/B0/B1的raw和PCRF八指标、低频组、用户得失及实际时间 |

H0与B1比较的是“原hinge/raw标度”与“B1 pairwise/标准化”的整体目标设置，**不能将差异单独归因全负例、softplus或标准化**。不为拆每个子因素再开损失矩阵。H0只在同一固定50项上继续原目标，不冒称完整复刻旧v6并集训练。

保留现有生成器、目录特征、CF缓存和PCRF系数；新增beam生成、CF模型评分和骨干更新均为0。严禁在validation目标上拟合或选择训练样本。固定候选意味着H50应与B0/B1逐用户一致，若不一致先排查候选或对齐错误。

## 3. 时间与工程范围

已有B1多初始化轮（包含4个新增小排序器训练及完整缓存评估）总计约11分57秒，说明缓存对照具有可承受的量级；这不是H0工期保证。新启动前先做原参考分数/排名一致性、原hinge公式/梯度一致性和实际吞吐profile；所有新代码与配置放独立目录，不改L0/B1冻结源码。

初拟两域合计计算硬预算30分钟，GPU等待上限15分钟；若profile预测超出，先停在预检并报告。超过10分钟继续后台运行，记录状态、来源hash及最终summary；不自动重试、延长步数、补seed或扫描margin。实际机器配置须在运行前依据profile明确，当前没有把未测量的估计写成已承诺完成时间。

## 4. 一轮后的处理

- 若H0接近B1且两者都超过B0：保留可复现提点，降低“B1特定目标是关键”的解释强度。接近的判断展示逐用户配对差值/区间和实际幅度；区间含0不能证明等效。此轮后不扫其他损失。
- 若B1在两域明显优于H0，且N10/H10方向一致：保留B1作为工作方案，得到比原目标继续训练更强的目标组合证据；不自动归因某一子因素或宣称创新。
- 若H0更好或跨域混合：完整报告两域取舍，不按域事后选择最优臂并冒称一个预先固定方案；先依据整体效果和预算选择后续统一版本。
- 若基线复现失败：记录为工程问题，先修候选/精度对齐，不作方法判断。

本计划不自动开启独立test。若主要目标已转为论文定稿，下一阶段应冻结一个最终方案与确认协议；若仍追求进一步提点，则以这次排序路线结果和已有覆盖缺口决定单项改动，不能凭L0负结果直接证明某种新结构必然有效。
