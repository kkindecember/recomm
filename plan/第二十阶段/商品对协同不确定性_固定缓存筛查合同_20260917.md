# 商品对协同不确定性：固定缓存筛查合同

2026-09-17，响应用户“继续找新机制”。本次重新授权的是机制探索，不恢复此前已停止的固定低频位置、旧36项用户门控、H0或蒸馏配方。Origin Skill：academic-research-suite。

问题：能否利用不同协同模型对**同一商品对的分差波动**，区分可靠的个性化顺序信息和不稳定修正？旧用户门控只有单模型分数统计；旧固定低频位置按频次一刀切。本次增加的是独立训练初始化产生的联合预测，不训练新门控。

已有依据：第9阶段三份独立CF模型及完整开发预测已保存。Toys/Beauty seed2023造成151/204个Top10命中丢失，其中68/100个在至少另一个seed上没有发生；有益修正也不稳定，因此它只支持检查信息价值，不能证明可识别性。旧第6阶段v8已测过候选注意力，不以“候选交互尚未试过”恢复该线。

固定主机制：对用户u、候选i,j，令g是当前B1原始分数的候选内z-score，c_m是第m个CF分数经旧PCRF频次校正和再次z-score后的分数，r为旧可靠性。三模型固定seed2023/2024/2025。

`d_ij = r·mean_m(c_mi-c_mj)`；`s_ij = r·std_m(c_mi-c_mj, ddof=1)`。

协同分差收缩为`d'_ij=sign(d_ij)·max(|d_ij|−s_ij,0)`，联合比较值`a_ij=g_i−g_j+d'_ij`。每候选以`sum_j sigmoid(a_ij)`排序，温度固定1，包含对角线恒定0.5。这是用于筛查信息的具体推理原型，不声称sigmoid是已校准偏好概率，也不把三个seed的标准差当作置信区间。

与逐商品方差不同，`Var(c_i−c_j)=Var(c_i)+Var(c_j)−2Cov(c_i,c_j)`保留共同波动。此恒等式和均值—方差风险排序均为已知思想；当前不声称原创定理。LiDu2025式(1)采用方差和；AcuRank2025、PUFR2023等已使用排序不确定性。论文价值取决于本地增量及进一步与近邻研究核查，不能只靠名称。

固定比较臂：

1. 当前B1＋PCRF（seed2023），并分别报告seed2024/2025同配方；不选最佳seed。
2. 三CF校正分数等权平均后融合：相同模型成本的主要参照。
3. 逐商品均值减一个标准差：普通保守打分控制。
4. 成对收缩但忽略协方差，使用`sqrt(var_i+var_j)`：隔离联合波动信息。
5. 成对联合波动收缩：上述主机制。
6. 每用户普通标量减权，减权比例等于主机制保留的协同分差绝对值总量/原绝对值总量：排除仅减弱CF的解释，不使用标签确定比例。

共有8臂。不扫描系数或阈值，不按新结果增加变体。复用现有C1候选50、B1分数及seed2023的CF缓存；只补其他4份冻结CF模型在两个域上的候选分数。训练频次/q1、B1及旧部署规则不变。先用seed2023的512行CPU前向核对缓存（绝对分差≤1e-4），当前完整目标名次必须精确重建；失败保留，不静默放宽。
