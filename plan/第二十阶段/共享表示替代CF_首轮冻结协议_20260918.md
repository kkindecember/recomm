# 共享 GRAM 表示替代外部 CF：Toys 首轮协议

## 问题与边界

固定当前 NDCG 最强配方 softmax.mean 的 seed20260917 实例，测试 C1/GRAM 的冻结历史表示能否替代三个 CF 的增量评分。选择第一个已有 head seed，不按本轮结果选择教师。保留 normalized.next_only.mean 的原登记，当前使用 softmax.mean 作为本实验效果参照，不改历史判定。

旧 decoder 蒸馏有梯度但关键排序迁移很弱；旧安全注入有接口与损失适配问题；扩大网络没有稳定泛化。本轮首先验证商品评分层面的知识可学性，不改变生成概率，不把共享评分头称为纯生成器。

## 冻结结构及融合

- 冻结 C1、原 B1、softmax 小头及候选50；无新 beam、无 backbone 更新。
- 用户表示：原 C1 pool_coarse 的512维表示；商品表示：C1 自有目录头权重，按商品ID重排，冻结。没有 CF embedding、CF user state 或外部教师分数进入学生推理输入。
- 编码器逐 passage 独立编码，位置0仍为历史提示。允许仅计算第一 passage 的等价缓存优化，但必须先通过完整 encoder 路径与原缓存特征的数值核验；不通过则停止工程门。在线部署可复用原生成已计算的该表示。
- 新头：用户/商品分别512→128，Tanh；拼接二者、逐维积、绝对差及原6项候选特征，518→64→1。末层为0初始化。新分支内使用无仿射 LayerNorm，不修改旧路径；固定商品表不新增可训练 embedding。
- 教师增量目标 t = mean_m z(z(CF_m) − 0.5 z(log(1+freq)))。保留三个教师分数平均后的真实幅度。
- 学生输出仅候选内中心化，记为 t_hat，不另做单位方差标准化，以保证零初始化等于无CF版本。
- 最终分数 g + r*t_hat，其中 g 为冻结 softmax 小头候选内标准化分数，r 沿用旧B1 Top10计算。教师分数 g+r*t。只替换这一项。

## 数据与最小对照

复用原6884条合法、覆盖目标且有未来窗口的 FIT 前缀，只使用即时标签或 CF 目标，不增加未来监督。这是为固定变量复用的受限样本，不能宣称代表全部前缀。复用原256条 calibration，核实与新头 FIT 用户互斥；它们仍可能被上游模型见过，不是整链未见交互。

1. 当前完整 softmax.mean 教师，三个CF。
2. 同一 softmax 小头去掉 CF，其他一致。
3. 新头普通即时 CE 训练，最终分数 g+r*t_hat。
4. 相同新头、初始化、样本顺序、更新数，用 MSE 学 t。该臂不另加CE，先检验单一迁移接口。

两训练臂同容量、同 AdamW(lr0.001, wd0.01)、batch128、10轮、clip5；按原 head/tail 全局各半权重。固定末轮，无校准/验证挑选 checkpoint。单初始化筛查，不作显著性或新颖性结论。

## 顺序与止损

1. 工程门：源/数据哈希；目标历史/候选ID对应；教师分数和原验证排名一致；零分支严格恢复无CF；候选置换、损失梯度与全/粗粒度编码一致性。
2. 从 FIT 以固定seed抽128个不同用户，每人一条前缀，训练400步MSE。通过需训练MSE相对零输出下降至少80%、最终教师Top10重合至少80%、教师要求升降的商品关系满足率至少80%。这是可学性投入门槛，不是科学显著性。门未过则停止扩展，记录原因；不改阈值、学习率或步数补跑。
3. 通过后，从相同初始权重重置普通CE及MSE两臂，完整6884条训练10轮。小样本已训权重不用于正式臂。
4. 在训练、原calibration及全部19412名开发验证用户评估；验证缺失目标也计入分母。报告 NDCG@10、Hit@10、低频组、教师列表重合、增量拟合MSE、升降关系。开发集历史反复使用；本轮不读test。
5. 继续门：迁移臂保住至少80%的教师相对同一无CF版本的NDCG额外收益，NDCG高于普通CE头，Hit较教师最多下降0.001，低频NDCG较教师最多下降0.0005。分母非正时不计算保留比例，不据此推进。
6. 如效果门通过，另行测实际推理成本并扩域；本轮不因减少模型数就宣称端到端加速。未通过则仅停止此固定配方，不推断所有共享表示内化均不可行。
