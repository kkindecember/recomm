# 未来软监督跨初始化与集成依赖：运行前合同

## 问题与固定预算

核查真实未来软标签相对同容量next-only及不使用本用户未来信息的局部平滑（global_local）的增量，能否跨小头初始化保持，并比较单CF与三个既有CF平均的部署。不是更换CF训练种子或端到端多种子重复，不声称解决上游随机性。

- 域：Toys、Beauty。小头种子：旧20260917直接读取；新20260918、20260919。
- 三臂：next_only、global_local、soft_future。每个域、每个新seed均跑三臂，禁止选最优seed。
- 同一冻结B1，沿用六维特征、258参数双头表达式、零输出层初始化；不同seed改变隐藏层初始化。同seed三臂初始化完全相同。
- 训练子集、用户、head/tail等权重均复用上轮。全批量梯度累积、chunk256、AdamW(lr=.01, weight_decay=.01)、clip10、30步。
- 两新seed×三臂×两域×30=360次优化器更新。CPU4线程，15分钟硬上限；后台tmux，状态文件可观察，不实时盯训练日志。
- 标签直接读取已经独立复核的组件拆解产物；next-only即时目标1，soft_future保留真实未来前三步的1/2、1/3、1/4软标签；global_local先验排除该用户全部FIT记录。禁止重估配方或调参。
- 验证使用冻结的audit_validation_cache：raw、单CF（current）、三CF平均（mean）；PCRF可靠性不变。无新候选生成、GPU训练、test读取。

## 预先固定的投入标准

按每个seed配对计算soft_future相对next_only、global_local的N10相对变化、绝对变化及Top10净命中；全部三seed逐项报告，另给均值和样本标准差。N10等均值±标准差仅描述初始化敏感性，不提供基于n=3的显著性结论。现有开发集被反复使用。

1. **三CF下的基础稳定性**：两域各自同时满足：三seed N10均高于next_only与global_local；三seed未拟合小头用户的N10增量也均为正；相对next_only的平均配对相对N10至少+0.5%，平均H10差不为负。
2. **超出平均局部平滑的投入余量**：在1通过之外，相对global_local的平均配对相对N10也至少+0.5%，平均H10差不为负。两域都满足才通过全局门槛。
3. **单CF独立实用性**：对current部署重复1、2，相同门槛；不能把mean通过、current不通过叙述成不依赖集成的增量。
4. **融合交互量**：每seed报告(soft−control的mean绝对N10差)−(soft−control的current绝对N10差)。它是固定配方下的描述性交互，不能反推用户行为因果或声称融合机制已经解决。

所有门槛是时间有限时的工程投入标准，不是统计显著性门槛。即使都通过，也只是稳定的借鉴式正向对照，不等于已具论文创新或CCF-B发表保证。若未过，不自动加seed、改阈值、扩大网络或启动生成器训练。
