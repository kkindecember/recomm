# Toys：有害修正是否可识别

Origin Skill：academic-research-suite / experiment-agent。状态：运行前冻结；用户“继续吧”授权实施这项有界检查。研究问题：只用推理时可见的信息，是否能够预测一次既定修正相对B1＋PCRF的收益或伤害？

上一轮冻结修正器在19412名开发验证用户上使305人的N10改善、623人变差，整体N10从0.08235733降到0.08156170。目标低频分组改善不能直接用于推理，因为真实目标未知。本轮冻结该修正器及全部分数，以识别能力决定是否值得继续研究。

## 协议与解释边界

- 本轮明确使用**既有开发validation标签训练诊断模型**。5折按用户ID哈希划分，每个用户的诊断预测由其他用户的数据训练；每个外层训练集再按另一哈希留约20%作阈值校准。外层评估用户不能进入模型拟合或阈值选择。
- 这只能检验同一开发分布上的可识别性，**不是train-only新方法成绩，也不是未经消费的确认验证**。不能把五折拼接结果称为一个已部署模型，不能据此重开test或宣布论文提点。上游固定修正器在上一轮仅以准备好的train前缀训练，但其研发过程已使用开发验证。
- 所有输入来自可见历史频次、候选频次、生成/协同分数、原排序与修正后排序的分歧。禁止真实目标、目标位置、目标频次、覆盖标记、用户ID、物品ID作为模型输入；用户ID仅用于划分。分组标签只用于结果分析。
- 冻结修正器，只允许整次采用或拒绝其输出。该动作粒度可能过粗，负结果只能停止这份固定修正器上的当前识别配方，不能证明所有局部纠错不可学。

## 对照与固定预算

1. 基线：全部保留B1＋PCRF；另一基线：全部采用已冻结修正。
2. 流行度探针：只用候选/历史流行度及其随排序变化的特征。
3. 完整探针：同一模型与预算，增加模型分歧、排序间距、调整幅度和候选证据对调整的支持程度。
4. 打乱标签控制：完整探针的拟合标签、校准标签分别按固定种子打乱（N10/H10成对打乱），外层仍用真实结果评价。这只是一次负控制，不是置换显著性检验。

三个探针各5折，使用相同HistGradientBoostingRegressor：squared_error，100轮、lr0.05、叶节点最多7、深度最多3、叶样本至少100、L2=10，early_stopping=False，种子20260917。直接回归每用户ΔN10，包含所有零变化用户。无类别重采样，无参数网格。

每折阈值候选固定为拒绝全部、采用全部、0，以及拟合集预测的25/50/75/90/95/99分位。仅校准集选择：要求平均ΔN10≥0.0001、ΔH10≥0、至少20个N10发生变化的校准用户被接受；满足时最大化校准ΔN10，同分选更少接受的阈值，否则拒绝全部。外层标签不参与选择。

CPU4线程，整轮1800秒硬超时；保留模型、折划分、阈值候选表、预测、动作和逐用户结果。不训练CF/生成器/修正器，不生成beam，不读取test，不启动Beauty，不在见结果后改特征或门槛重跑。

## 判定

完整探针满足以下全部工作门槛，才标为“值得做训练分布迁移检查”：全体拼接N10至少高于基线0.0004（约0.5%，仅投入门槛）、高于流行度探针和打乱控制，H10不低于基线，至少4/5折N10有正增量，发生N10变化的用户上收益/伤害AUROC≥0.55。

否则停止这份固定修正器上的当前识别配方；若只有AUC可辨或仅部分分组改善，不能升级为有效方法。仍完整报告各臂和各折，不能以命中某个门槛片段替代整体判定。

报告全体八指标、N10/H10逐用户得失、低频/其他目标分组、各折变化、被接受与被拒绝的收益/伤害、对改变用户的AUC。2000次配对bootstrap仅描述固定外层预测，未纳入折训练依赖、随机种子和长期选型的不确定性，不作确认性显著声明。知道真实标签才挑修正的oracle仅作分解，不是可部署方法。

普通风险排序已有工作，例如[Wang等，SIGIR2012](https://www.microsoft.com/en-us/research/publication/robust-ranking-models-via-risk-sensitive-optimization/)；本轮不将门控或风险权衡声明为创新。实现使用[scikit-learn 1.6.1官方接口](https://scikit-learn.org/1.6/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html)，明确关闭默认可能触发的early stopping，避免额外选模。
