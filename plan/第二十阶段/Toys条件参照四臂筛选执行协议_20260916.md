# Toys条件参照四臂筛选：固定执行协议

2026-09-16。用户“那进行下一步吧”授权后实现。Origin Skill：academic-research-suite / experiment-agent；配置在任何新增方法验证结果产生前固定。研究来源：[综合方法计划](论文主线与九月底方法冻结计划_20260916.md)。本页是首轮实现，不代表创新性或有效性成立。

## 1. 一轮回答什么

在同一B1＋PCRF基础上，类别语义条件下的协同背景差值，是否提供普通可学习融合和简单背景参照之外的排序增量？只做Toys四臂；不自动Beauty，不更新生成器/CF，不生成新beam，不读test。

| 臂 | 起点与额外信号 | 新训练 |
|---|---|---|
| A_frozen | 冻结B1＋PCRF seed2023 | 无 |
| B_plain | A分数＋小修正器；第六输入为z(CF) | 30次全FIT更新 |
| C_semantic | A分数＋同型修正器；第六输入为z(CF−语义参照平均CF) | 同B |
| D_simple | A分数＋同型修正器；第六输入为z(CF−简单参照平均CF) | 同B |

三臂共同的前五维为z(B1残差分数)、PCRF校正后的CF、z(log训练频次)、原C1倒数rank、冻结PCRF可靠性。6→16(tanh)→1(tanh)，共129参数，新增修正限制在±0.5个最终分数单位，输出层零初始化，同seed20260916。三臂起点均为A，不给C增加参数、更新或选模机会。

这里的“语义”首轮限定为已有商品类别画像，不另训文本编码器。成功也只支持该实现，失败不能推广为所有语义参照无效。C/D包含新参照信息，B只有原融合信息；同参数量并不意味着三者拥有同样的信息。

## 2. 参照构造与信息边界

- 商品类别来自既有prepared catalog（468维含padding）。类别IDF为log(11924/类别覆盖商品数)，全目录通用类别权重为0。每商品画像归一化，历史内取均值，再做L2归一化；全零画像保持零。
- 参照库由prepared TRAIN恢复完整训练序列，取最近20项；排除全部4853名C1训练/校准用户，剩14559名用户。对每个query再排除该用户自身。完整训练语料的频次及既有CF权重属于共享训练信息，不使用validation或test目标构建参照。
- 硬匹配历史长度分组1—5、6—10、11—20。组内按四个标准化特征的平方距离找最近300人：log(1+长度)、平均log(1+频次)、log频次标准差、频次≤5的历史占比。均值/尺度仅从参照库估计。
- 按距离将300人分成30个连续块，每块10人。C在每块选择类别余弦相似度最高者；D在同一块按固定、与标签无关的哈希优先级选一人。两臂均30名参照，C语义同分也使用该优先级。
- 哈希query键只用用户ID与可见history。旧sample_key包含下一目标商品，**不得用于新参照采样**。
- 背景分数是30个冻结CF预测logit的算术平均。利用点积形式先平均归一化用户向量，再与候选向量相乘；不再归一化均值向量，否则不等于平均logit。

这种匹配是控制部分可见变量的近似匹配，C/D在同一距离块内仍可能有细微流行度或长度差异。完整记录两臂类别余弦、四维匹配误差、邻居重合率、零类别画像率，不称因果识别。背景差值也不等于已被证明的“纯协同增量”。

## 3. 数据、评分、优化与选择

复用原22095条训练缓存：21839 FIT、256 calibration，其中FIT覆盖目标12399条，未覆盖9440条。训练标签只取合法训练前缀的下一商品；未覆盖目标不塞进候选。沿用FIT head/tail各半权重；每次梯度覆盖全部有效FIT，512条只是累积块。

三臂AdamW lr0.01、weight_decay0.01、clip10，固定30次更新；目标为标准化最终分数上的全部49负例pairwise softplus。所有臂共享初始化、训练顺序、候选、目标和预算。calibration不选步数，不按途中validation择优，三臂完整训练后一起评估。

验证使用19412名全体用户。A直接复用冻结B1分数，再按原PCRF规则重算，要求全部逐用户rank精确一致。训练侧B1起点由原checkpoint在CPU FP32、chunk128前向计算，所有臂共用；固定64名验证用户核对该前向与原分数的最大误差≤1e-6。CPU舍入差异不替换冻结验证分数。新CF向量实现对64名既有query候选logit核对误差≤2e-5，原CF分数缓存不被重写。

原PCRF先按B1分数稳定排序再融合；新四臂沿用该候选顺序处理同分。所有50候选不变，H50必须逐用户保持；这项一致性不能被当作新收益。

## 4. 统计和去留

报告四个截断的NDCG/Hit、全体/低频/较高频及C1训练用户内外分组。主比较C对A、B、D，另列B、D对A；2000次用户配对bootstrap，seed20260916。展示N10改善/变差人数、H10新增/丢失人数、前5名改善用户占正收益比例。

机器筛选：C的全体N10未同时超过A/B/D，标记STOP_SEMANTIC_EXPANSION；三项均为正，仅标记REVIEW_BEFORE_BEAUTY，还需结合实际幅度、区间、指标代价和个例集中度人工判断，不能自动宣称有效或自动跨域。没有按1%—2%设置事后显著性门槛，也不因CI含0宣称等效。

这些都是长期开发validation上的描述性比较，未做多重比较校正，不含训练seed不确定性。覆盖选择、头尾权重、群体差异和所有失败臂均完整保留，不把covered或有利子组结果替代全体结论。

## 5. 资源、产物和运行

CPU固定4线程，GPU不可见；profile硬上限15分钟，正式worker硬上限2小时。启动前实测完整FIT梯度、192条匹配和最长512条参照历史的CF编码速度，保守估计超预算则不进入正式训练。超过10分钟的任务在tmux后台运行，监督器记录进程存活和时间；只在硬超时停止自己的worker进程组，不自动重试。

正式运行前须通过8项科学不变量测试：背景评分等价、稳定并列/自排除、匹配分层与语义选择、D不依赖语义、query键不依赖目标、通用类别处理、原PCRF排名一致性、零初始化与累积梯度一致性。另做全量冻结基线、缓存来源和hash检查。
