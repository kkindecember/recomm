# 候选覆盖与转移关系：零训练核查

2026-09-17，结果计算前固定。目的：判断当前强基线的漏召回是否仍有现成 CF 信息支持，以及训练转移支持是否呈现值得研究的模型分工。不是新方法实验，也不构成独立确认。

- 必比基线 `normalized.next_only.mean`，三个已登记小头初始化；保留对应 `normalized.next_only.raw`。同时读取已有三个 CF 的全目录目标名次，不重训、不重新解码、不读取 test/Sports。
- Toys/Beauty 全部既有 validation 用户。按用户 ID、目标商品对齐；核对候选内目标位置与三初始化候选一致性，重建登记基线 N10/H10。
- 从 prepared train 中每条前缀的“最后历史商品→目标”建立有向邻接集合，忽略重复次数；不把 validation 目标加进图。查询取可见历史最后20件。
- 互斥分组顺序：最后一件与目标有训练直接边；仅更早历史有直接边；无直接边但任意历史经一个中间商品可达目标；以上均无。这是目标知情的诊断标签，禁止用于部署路由。二跳可达不是有用预测，也不是对两篇论文完整分类的复现。
- 全体及四组报告用户数、候选覆盖、强基线/未加CF分数 N10/H10、配对命中变化；报告各单 CF 与任意 CF 在10/50名内覆盖的候选外目标数。任意 CF 并集是 oracle 可用性上界，不等于平均模型，不是固定10/50预算的新系统。
- 主问题不预设正结果。缺乏模型优势交叉时，不以“CF负责记忆、生成负责泛化”支持新门控；出现交叉也仅为必要线索，不足以恢复旧门控。覆盖增量本身不能解锁旧候选扩展训练。
- 新训练0步、GPU0、仅CPU缓存分析；单次预算10分钟。保存输入/源码哈希、逐用户结果、分组汇总、status；校验失败停止并保留产物。

文献边界：2603.19809 的记忆定义以最后一件为准；2606.17276 的一跳支持可来自任意历史。二者不能混称。本核查分别保留这两种直接支持信息；不宣称读过目标即可部署，不以现有分组差值识别因果。
