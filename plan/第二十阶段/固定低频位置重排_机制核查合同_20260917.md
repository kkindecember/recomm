# 固定低频商品位置：机制核查合同

2026-09-17，执行前记录。Origin Skill：academic-research-suite。本项属于已授权的方法论证和低成本缓存检查，不训练新模型、不读取test，不改变现有部署规则。

问题：普通融合的低频损失有多少可由跨频次组的位置竞争解释？在保留B1＋PCRF已取得的全部低频商品名次后，原有协同分数能否继续改善其他商品排序？

机制：对每个用户，按训练频次≤旧q1（Toys5、Beauty6）标记50候选中的低频商品。保持这些商品的绝对位置及内部顺序，其余位置按`z(B1_raw)+z(CF)`重新填入非低频商品。没有目标、目标频次或验证标签进入该排列函数。该操作保证所有低频候选的名次与原B1＋PCRF逐项相同，故任何低频目标的Hit/NDCG保持；候选外目标仍为零。这个性质不能保证其他目标或总体成绩上升。

它是受约束排序的一种简单适配，**不声明原创算法或新定理**。FA*IR、一般约束排序及FINEST等已有相关研究，具体差异和近期工作需要如实核对。旧用户门控要求预测修正是否有益；本项直接限制可改变的名次，不拟合旧36项分数统计，也不恢复H0。

固定六臂（λ均为1，不按新结果改权重或分组）：

| 臂 | 内容 | 作用 |
|---|---|---|
| current | 当前B1＋PCRF | 参照 |
| plain | 同B1分数的普通CF融合 | 重现总体/低频取舍 |
| pop_constant | 简单频次校正后固定权重融合 | 强简单对照 |
| group_slots | 保持每个位置的频次组标记，两组各按plain顺序重排 | 只约束组别位置，不保护单个低频商品 |
| protect_tail | 固定全部低频商品位置，只重排非低频商品 | 主机制检查 |
| protect_non_tail | 固定全部非低频商品位置，只重排低频商品 | 对称控制，隔离组内变化 |

检查范围：两域全部原开发用户；原B1和旧λ=1曲线精确名次对齐；每用户50项无增删；所有受保护商品逐项名次一致；所有目标组仅用于事后统计。主结果报告全体/低频/其他频次的八项指标与命中得失，始终保留各臂。

同时只读复核现有监督：冻结129参数B1在旧FIT/calibration缓存上做CPU前向、不更新参数，核对旧calibration指标；比较固定配方的组内效果、CF排序及样本覆盖。另用上一轮已冻结的两类权重范围，检查旧calibration选择的权重在开发集上的已存曲线位置，明确它不是独立确认、没有写入部署参数。多前缀按用户等权另报。

判读先于结果：若protect_tail在两个域的全体N10均高于current、H10均不低于current，且保护恒等式成立，才称“这一简单约束的双域开发可行性获得支持”；否则不把它作为已成立的方法基线。即使通过，仍需与group_slots/简单融合比较并判断原创性、幅度和泛化，不自动启动大实验。不能根据结果放松保护集合或再加门控。
