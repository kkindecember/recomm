## 2. 第一项：用已有缓存拆分分数、残差和候选的作用

### 为什么优先做

原PCRF的base是生成sequence score；GACR组合的base是`1 / C1生成rank + residual`，再在GACR top50中标准化。非线性分数变换即使保持单路排序，也会改变融合结果；候选集合变化还会改变标准化和tail_mass。现有六臂比较不能将总增益唯一归因于129参数残差。

逐用户账本中，组合相对原PCRF的N10增量+0.002211，有+0.002178来自双方都能在Top50覆盖目标的用户；新增/丢失覆盖两项合计仅+0.000032。相对C1+PCRF，新增覆盖13名用户没有进入组合Top10，丢失覆盖14名用户损失4个Top10命中。这是分组记账，不是候选替换因果效应的估计，却足以说明单纯增加候选不是当前最有依据的下一步。

### 固定对照

保留已经完成的六臂，新增下表三个控制；不按先出来的结果删臂、换权重或挑更弱基线。

| 编号 | 候选与分数 | 排除的替代解释 |
|---|---|---|
| R0：已有 | 原GRAM beam50，原sequence score → PCRF | 强参照，N10=0.078679 |
| R1：新增 | 原GRAM同一beam50，base改为`1 / 原生成rank` → PCRF | 单靠分数尺度是否已能得到组合的大部分收益 |
| C0：已有 | C1 beam50，原sequence score → PCRF | C1继续训练对照，N10=0.078484 |
| C1：新增 | C1同一beam50，base=`1 / C1生成rank` → PCRF | 分离倒数rank变换与学习残差；等价于并集零残差时优先保留生成50项 |
| C2：新增 | 固定C1生成50项，base=`1 / C1生成rank + 已有冻结residual`，按此分数排序后PCRF | 在不引入额外目录候选时，已有残差是否仍有用 |
| G：已有 | 原并集的冻结GACR top50 → PCRF | 完整组合，N10=0.080890 |

这里的C1、C2只是本表控制编号，不是历史checkpoint名称。实施时机器臂名应使用`c1_reciprocal_pcrf`、`c1_fixed_candidates_residual_pcrf`等明确名称，避免和历史CF1-C2混淆。

所有臂冻结lambda=1、beta=0.5、gamma=1、q1=5及原稳定排序。每臂按实际进入PCRF前的候选顺序计算tail_mass；不得复用来源不一致的历史元数据。C2只对子集中的已保存六维特征调用原残差模型，不重新提特征、不训练新残差。每臂候选内的PCRF必须保持其Hit@50。

主比较：G相对`c1_reciprocal_pcrf`的NDCG@10；同时完整报告G相对R1、G相对C2、C2相对C1以及各臂相对R0，连同Hit@10、四截断指标、频次两组、C1训练用户内外和命中得失。不能只挑有利的比较宣布机制成立。

用原`c1.predictions.jsonl`、`gacr.predictions.jsonl`、`candidate_features.jsonl`和父预测即可构造这些控制。先核对输入哈希，并要求CPU重建的已有GACR/PCRF逐用户rank与正式记录精确一致；有差异先报告数值问题，不把差异当新增收益。只读prepared train/validation，目标只用于最终算指标。CPU最多4线程；建议单次30分钟上限，工程失败保留attempt，不自动扩预算或重试。

统一3000次配对用户bootstrap、seed20260912；只解释为重复开发validation上的描述性区间。当前才提出这些对照，所以属于事后机制验证，不能改称原始预注册消融。均值差、命中数和区间同时读，不按区间跨零自动判定等价，也不补跑到显著。

### 结果分支

- 若简单倒数rank+PCRF基本解释G的收益：以较简单方案为性能候选，将主问题转为不同推荐分数的可比性；残差或目录头必要性尚未建立。不要继续堆复杂模块来保留原叙事。
- 若固定C1候选+残差仍有增量，而G对它无额外收益：优先保留固定候选的排序方向，并检查省去目录候选后的覆盖和成本；新设计必须区别于历史GACR和CF1-C2。
- 若完整G在上述比较中仍有额外收益：记录新增候选在前十的实际兑现，再把候选与排序协同作为值得深入研究的线索。
- 若差异很小且区间宽：结论是机制尚未分清，结合跨域和训练seed判断；不凭一个局部高点推出方法贡献。

## 3. 第二项：原组合冻结到Beauty

这是检验迁移性的直接实验，有明确已有Toys正证据，优先于再开一条未经本地验证的完整架构训练。

- 使用已存在的Beauty C1、GACR-v6 residual seed2023与PCRF item-head seed2023，先登记确切文件和SHA。只做评估，不重训C1或残差；缺少匹配权重时记录缺失，不能私自替换模型。
- 22,363名官方validation用户；同一用户上同时比较原GRAM、原PCRF、C1、C1+PCRF、GACR、GACR+PCRF六臂。
- 必须先取得与C1/GACR一致的FP32、TF32关闭、原生beam50父参考。现有Beauty PP smoke使用历史缓存，不能代替这份同精度全量父参考。
- 固定Toys组合的数学规则及lambda/beta/gamma，频次分层沿用既有域规则与Beauty q1=6；这是预先声明的域适配，不看Beauty指标后改阈值。不能一边写“原Beauty PCRF”，一边把其阈值静默改成5。
- 严格检查目录行映射、候选顺序、六维特征、父参考rank及输入哈希；同等报告C1训练用户内外。外组只表示未用于C1那次训练，不等于所有组件均没见过这些用户的训练历史。
- 主比较是组合对原PCRF的N10，Hit@10同时报告；低频及Hit@50仍作取舍，不事后恢复旧阶段“全部截断不降”的硬门槛。
- 建议单卡、正式评估总硬预算24小时，含需要新增的父参考；工程检查另设30分钟。按实际空闲显存准入，不承诺沿用Toys3.18小时就一定完成。

这是已开发过的Beauty上的冻结跨域检查，不是全新未见域。不得读取test来决定是否继续；现有Toys/Beauty test已有历史消费，本组合也没有新test结果。

## 4. 何时补seed，何时进入新方法设计

若固定对照和Beauty仍保留有实际意义的额外收益，优先复用已存在的GACR residual seed2024/2025检查重复性，C1和PCRF head固定。随后若需要检验协同头随机性，再固定残差、改变item-head seed；不要把两类seed一起变化后称单一机制稳健。

这些都不等于独立重训GRAM或C1。若论文需要声称骨干训练随机性稳健，则另设计骨干seed实验，并核算成本。先用现有权重回答最便宜的关键问题，避免立即做全部seed笛卡尔积。

若Toys简单控制解释了增益或Beauty明显反向，停止把当前组合升级成通用主方法；保留准确结果和取舍，再只选择一个能解释失败的新机制。不是把所有已有工作宣布无效。

下一份方法草案至少应有四项内容：

1. **本地可测的问题。** 例如生成分数与协同分数的尺度失配、可靠性估计误差、候选替换造成的前十损失；由上面控制决定哪一个有证据，不一次全做。
2. **具体学习或计算机制。** 明确输入、输出、训练标签、作用位置和成本；“加一个gate”“加教师”“加行为分支”本身不是完成的设计。
3. **历史与文献差异。** 对照GACR六维残差、PCRF启发式频次权重、第10阶段union/PCRF锚定和第18阶段PCPS，逐项解释新机制解决了什么旧方案没有解决的问题。
4. **能推翻假设的对照。** 除原GRAM/PCRF外，加入本轮最强简单控制；需要学习时保留等预算控制、合法train前缀和不依赖未来信息的特征。

“完整EAGER迁移”可作为之后的架构备选，它已有共享encoder、行为/语义双decoder、协作训练和置信合并，不能把双流融合本身宣称为新贡献。[作者论文](https://arxiv.org/html/2406.14017v2)

“完整PPAC迁移”也仍是未做事项；当前只试了PP加性信号，原方法还包含训练及全局/个人流行度作用建模。五折均选eta=0不证明完整PPAC无效，也没有提供立即投入完整PPAC+EAGER联合训练的正依据。[作者论文](https://arxiv.org/html/2402.07425v1)

建议先用上述一轮有区分力的验证决定研究问题，再投入一条完整新训练路线。当前可以给出清楚的优先级，还不能承诺下一种设计必然提点或已有足够论文创新性。
