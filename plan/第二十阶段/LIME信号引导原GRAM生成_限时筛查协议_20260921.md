# LIME信号引导原GRAM生成：限时筛查

2026-09-21。用户授权立即筛查。Origin Skill: academic-research-suite / experiment-agent，内联执行。

## 目的与边界

验证冻结LIME信号能否直接改善原始GRAM生成结果。只用历史开发集，旧模型曾按开发集选轮，因此不称独立测试或最终论文成绩。不要修改正在进行的新划分双卡训练代码、输入或调度；不读取test，不训练新模型。

## 冻结设计

- 原始GRAM：Toys阶段二epoch30，Beauty阶段一epoch25；原词法ID、历史20、beam50、FP32、TF32关闭、length_penalty=1。不使用C1、目录头或残差后排。
- 固定LIME seed0/cal2048资产。专家：SASRec单独、LIME三专家融合含原历史校准。复用已保存门控权重；不重新拟合门控。
- 从既有LIME evaluation用户按SHA256(`20260921|lime-decode|域|用户`)排序选3名smoke、128名tuning、512名evaluation，互斥且全部排除2048门控拟合用户；不按命中与覆盖挑人。smoke另用最长历史输入，只作无标签工程检查。
- 每种信号仅alpha=0.1/0.3。tuning按NDCG@10选，alpha=0原GRAM作为共同回退选项；并列优先较小alpha。evaluation不再选择。
- 专家分数按作者逐用户min-max归一，LIME用保存的三权重和历史惩罚；按exp(20*score)形成全目录物品质量，沿词法trie求和为前缀条件分布。20是已有门控训练标度，不新增搜索温度。
- 在原trie掩码后混合概率。保持每个前缀原合法词元总质量m，输出log(m*((1-alpha)*p_native_conditional+alpha*p_expert))。alpha=0严格保留原模型。此为AGRec启发的适配，不是作者代码复现；保留GRAM变长词法ID与原长度惩罚。
- 所有方法最终统一过滤最近20件历史物品，原50序列不补满；引导分布不另作历史硬掩码。独立LIME也按同一资格规则输出Top50。
- 保存原生成完整路径的每步原词元分数，用相同概率混合规则对原50路径重算，作为严格同终点规则的late-only对照；另报直接用LIME分数重排原候选及LIME独立推荐。
- 主要看直接生成N10/H10/H50；固定一个seed，bootstrap仅作用户条件下的描述性区间，不作正式显著性或骨干稳定性声明。

## 工程、成本与停止

先CPU数学测试，再每域3名smoke验证原生成与零引导完全相同、路径分数可复算、编码缓存与原generate一致、原checkpoint不变。确保用户/商品/历史/专家映射匹配，复现已存LIME Top50。失败停止，不在错误接口上解释效果。

两个worker仅使用GPU2/3，各需至少11GiB空余准入，最多等待10分钟；不使用正在新训练的GPU4–7。进程内显存分配上限约11GiB，CPU各2线程。各域推理硬上限2小时，先profile，预计超预算不执行正式筛查。OOM及超时记录为工程不完整，不算科学负结果。只终止本轮自己启动且身份核验的进程。

evaluation中LIME引导在双域N10均相对原GRAM至少+1%、H10均不下降，记为值得在新流程复测的初筛信号，不等于证明创新。与late-only及单专家的比较单列：只有提前搜索带来实际额外价值，才支持继续做生成阶段机制。否则记为性能线索/证据不足/停止当前配方；不自动追加权重、温度、用户或门控。小样本区间跨零不证明无效。

预期每域最多2176次正式beam，外加工程检查；实际成本由短测和实时共享负载给出。无论正负均保留全部臂，不把最佳tuning结果当evaluation成绩。
