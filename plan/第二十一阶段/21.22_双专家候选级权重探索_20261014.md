# 双专家候选级权重探索

Origin Skill: academic-research-suite / experiment-agent，内联执行。

用户在专家选择完成后明确要求继续候选权重。当前以 SASRec＋BGE 文本为探索组合，ItemCF 保留在旧三专家参照中。本轮只筛选方法，不展开论文完整实验矩阵。长任务在 tmux 后台运行，通过 artifacts/status.json 查看，完成后用户返回分析。

## 依据与范围

旧三专家锚定校正中候选级优于用户级，但直接分数修正也有效，eta=1 的权重调整优于 eta=.1。单独从头训练的简化权重头在 Toys 和 Beauty 都未超过其用户级对照。因此本轮固定使用已有双专家共享融合器作为锚点，eta=1、KL=.2；不把旧三专家收益直接当作双专家证据，不恢复旧三专家真实生成队列。

共享基线来自 `expert_resource_recovery_20260923_v1/removal/without_itemcf`，原 gate_calibration 用户拟合的权重与历史惩罚冻结。把该线性门控投影为只接收两个专家统计量、输出两个专家权重及历史惩罚的等价形式；逐行核对旧保存值和512用户的排名。专家分数从已有只读缓存读取索引0和2，候选集合及特征均不使用 ItemCF、旧三专家融合或其候选。

## 固定比较

1. baseline：冻结双专家共享融合。
2. user：每用户一个权重调整向量，在固定候选集合内共用；集合外维持 baseline。
3. candidate：每用户、每候选独立权重调整；集合外维持 baseline。
4. scalar：同一候选特征直接输出分数修正，检验收益是否必须通过专家权重获得。

三种训练头均为27→32→2，962参数、零输出初始化、相同训练用户和预算。user 的14项候选输入恒为0，有效输入13项；candidate/scalar 使用全部27项。scalar 使用两个输出之差的 tanh，保持同等名义参数量、零初始化和最大绝对分数改变量上界1，但不强制专家凸组合；这不是函数族完全等价的对照。

候选集合为 SASRec、文本、冻结双专家融合各自前50的并集，最多150，过滤最近20历史，与最终评估过滤一致。所有组共用集合，不注入真实目标；目标在集合外的训练行仍保留。用户级对照属于集合内共享权重，不能把该比较表述为胜过任意全目录用户级模型。

记原权重w0，双专家分数s，冻结历史惩罚后的融合f0，网络输出z，则权重调整为 `softmax(log(w0)+z)-softmax(log(w0))`，分数为 `f0+Δw·s`。scalar 使用 `tanh((z0-z1)/2)`。损失为温度20的精确全目录CE＋.2 KL(原分布||新分布)，压缩计算集合外归一化质量；初始化精确恢复f0。

## 训练、评价与判断

每域三小头seed0/1/2，AdamW lr=.002、wd=.001、batch64、最多20轮。仅 ranker_fit（Toys2773/Beauty3310）标签训练；沿用21.19用户hash五折中的一折选择0/4/8/12/20轮，按内部heldout损失选轮数，再全ranker_fit重新拟合。特征标准化仅使用对应拟合行。固定全部模型后才评估全验证集。

主要探索池是原 full_validation 中既非旧512、亦非任何训练角色的用户：Toys15406、Beauty17766，检查与共享锚点和小头拟合用户均无交集。另报告旧512与全体验证；不得混用这些分母，更不得把纯专家排名与真实生成直接比较。这个验证池此前已经反复使用，不能称作未见过的确认性样本。本轮不读test，不训练上游生成器或专家。

报告逐seed和均值NDCG@10/H10/H50、candidate−user、candidate−scalar、三头分别相对baseline、逐seed前十新增/丢失。描述性配对bootstrap先对小头seed求每用户效用均值再抽用户，2000次；不把seed当额外用户，不声称覆盖上游随机性或研究选择不确定性。多项比较不作确认性显著结论。

candidate 相对 user 双域方向为正、相对 baseline 有实际收益，才值得进入真实生成；若 scalar 更好或相当，不声称专家权重是唯一收益来源。小头筛选结束后停止，不自动扫参数、不自动启动生成。真实生成是否超过GRAM和三专家收益差距需要后续单独核验。

## 执行与核验

CPU两域并行，每进程2线程，无GPU租约。每域运行硬上限4小时，后台监督每15秒更新总状态、检查进程和退出码。按先前同类缓存/小头规模，预计约15–40分钟，实际取决于共享CPU/磁盘；不是承诺。失败保留输出与错误，不覆盖旧暂停任务。

核验：移除专家扰动不变；零初始化精确恢复；双权重归一；精确全目录损失/梯度与稠密实现一致，包括集合外目标；全部历史双专家样本的共享基线复现；每头每域21用户独立NumPy前向与排序；集合外分数严格不变；保存后重读排名核对聚合指标；代码、输入、输出散列和输入文件未修改检查。

输出：`artifacts/phase21/dual_candidate_gate_20261014_v1`。主状态 `status.json`，分域状态 `{Toys,Beauty}/status.json`，日志 `worker.log`，最终 `summary.json` 与 `verification.json`。保存seed0在既定2048用户上的分数供未来生成复用，但本轮不解码。

命令：`bash experiment/phase21/run_dual_candidate_gate.sh`。
