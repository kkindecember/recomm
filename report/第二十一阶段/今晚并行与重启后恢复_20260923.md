在项目目录手动恢复：

```bash
bash experiment/phase21/run_night.sh resume
```

如需后台运行：

```bash
tmux new-session -d -s s21_night_20260923 'bash experiment/phase21/run_night.sh resume >> artifacts/phase21/night_run_20260923_console.log 2>&1'
```

重启后遗留的RUNNING不是进程还活着；恢复入口会核对系统boot ID和进程启动身份，避免把重用的PID认作旧任务。完成任务自动跳过，被重启打断的任务继续；真正的FAILED不会默认重复尝试，应先读failure文件、诊断后再用--retry-failed。

如果只有最后一行写到一半，会保存残片再恢复；完整记录损坏、名单错位或输入不一致会报错，不会静默删掉用户。完整512人齐备后才生成最终对照结果。后续直接说“恢复今晚的实验”即可沿此入口处理。
