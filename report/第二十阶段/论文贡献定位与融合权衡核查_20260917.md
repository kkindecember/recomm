**投入判断：停止新增结构筛选，先围绕“协同融合的总体收益与低频准确率损失”形成一份具体贡献论证。** 这是PCRF已有问题的收敛，不是宣布新的方法已经有效。今天的新对照显示：简单融合/频次校正的能力比只看原固定权重时更强；当前B1＋PCRF也不能被表述为在这类对照中双域总体最优。找贡献必须把这些对照纳入，而不能继续只要求新模块超过一个固定版本。

## 1. 本次实际完成的检查

读取Toys/Beauty已经保存的B1残差分数、C1候选50、协同分数和训练频次。先精确重建两域B1_raw与B1＋PCRF全部逐用户目标名次，随后比较两类固定权重曲线：

- 普通融合：`z(B1) + λ z(CF)`。
- 简单频次校正融合：`z(B1) + λ z(z(CF) − 0.5 z(log(1+训练频次)))`。

每类λ从0到2、间隔0.025，再加4、8及CF单独排序极限，共84个设置；两类各84个、每域168个。两域分别19,412/22,363人。低频阈值沿用Toys≤5、Beauty≤6；不根据新成绩改变分组。保留完整用户、固定候选，H50恒定。

执行前写出协议、脚本哈希、参数范围和300秒预算；实际CPU耗时22.51秒。没有训练新模型，也没有把开发集上较高分的参数切换为当前部署配置。原B1＋PCRF和B1_raw精确名次复核通过，输入哈希前后不变。后续从保存名次重算3,042个指标值，并用另一种逐项折扣求和核验N10。

产物：[status](../../artifacts/phase20/b1_contribution_audit_20260917/status.json)、[协议](../../artifacts/phase20/b1_contribution_audit_20260917/protocol.json)、[完整结果](../../artifacts/phase20/b1_contribution_audit_20260917/summary.json)、[完整曲线CSV](../../artifacts/phase20/b1_contribution_audit_20260917/tradeoff.csv)、[指标复核](../../artifacts/phase20/b1_contribution_audit_20260917/verification.json)、[分析脚本](../../experiment/phase20/audit_b1_fusion_tradeoff.py)。

**统计边界：** 这是重复开发集上的描述性权重扫描。每类“最高总体分”在同一开发集上选出，是偏乐观的参照，不是合法选模后的独立验证成绩；不报告事后筛选的显著性，不证明等价或最优，也不把有限网格当作所有简单/学习融合方法的完整集合。单个上游与残差seed，不能外推训练随机性或其他骨干。当前1%工作门槛仍适用于上一轮已冻结实验，不是任何论文都必须额外涨1%的标准。

Toys当前B1＋PCRF的点估计仍高于两类曲线的最高全体N10；相对简单频次校正的差仅约0.170%，不能据此宣布自适应可靠性有稳定的独立贡献。普通融合的全部扫描点都未达到当前低频N10，说明单纯调整本次标量权重没有复现这项低频收益。

Beauty普通融合最高全体N10比当前高2.37%，但低频N10下降8.01%。这不是免费提点。简单频次校正则有8个扫描点在全体N10和低频N10两个轴上均超过当前点；以λ=0.75为例，全体+0.00017355、低频+0.00015378，但低频H10净少1人。因此不能写成所有指标全面支配，也不能将开发集扫描点直接升级为正式方法。

**得到的具体问题：** 现有协同信息有准确率收益，但保护低频与提高总体并不总是同向；同一套校正和可靠性规则在两个域上也没有统一的点估计优势。数据支持研究这种取舍，尚未证明它的唯一成因、可预测性，或新的自适应机制会有效。

|---|---|---|
| [LIME-Rec，2026-08预印本，正文方法与附录E/F](https://arxiv.org/html/2608.01260v1) | SASRec、ItemCF、冻结语义表示的分数融合，轻量用户权重与历史校正；明确定位为收益归因的恢复检验 | “轻量三路融合也能提点”已有极近邻。它使用validation拟合，再到test评估；不能把这种监督量与本地train-only拟合直接混比。已有该类研究也不等于所有简单方法都不能发表。 |

## 4. 哪些贡献已经有证据，哪些仍然空缺

| 可写的候选主张 | 现有证据 | 判断 |
|---|---|---|
| 外部协同融合改善原生成模型 | 旧PCRF双域及冻结test；最新B1双域、三个残差初始化的开发成绩 | 有效性基础可保留；最新B1不是旧PCRF的test结果，也不是三次完整骨干seed |
| 频次校正能缓解普通融合的低频准确率损失 | 旧组件消融；今天两域同B1分数的固定权重曲线 | 有问题与部分机制证据；不等于因果去偏、曝光公平或新颖性成立 |
| 现有自适应可靠性规则是关键创新 | Toys只比简单校正略高；Beauty存在简单校正的更优N10点 | 当前不足，不宜放进标题或作为已证明的核心贡献 |
| 增大网络或历史交互带来有效新信息 | 既有完整对照未支持 | 不继续按此包装主体 |
| 教师优势已经迁移进生成器 | 完整KL、短程筛查及普通顺序监督未建立所需收益 | 不成立，不作为当前主线扩展 |
| 极低开销或129参数替代完整模型 | 六维分数依赖已有目录头/生成器/CF；未做完整部署成本证明 | 不能用新增MLP参数数目代替系统成本证据 |
| 新机制稳定改善总体—低频取舍，并超过简单强对照 | 目前没有这样的完整方案与结果 | 这是方法论文仍需填补的缺口 |

当前可保留的一句话研究问题为：**在冻结的生成候选上，如何利用协同排序信息，同时控制对低频商品准确率的损害，并避免固定校正规则在不同数据条件下失效？** 这是待检验的问题，不是已确认无人研究的空白。

对应的贡献草案必须保留一个明确空格：

> 针对上述取舍，我们提出〔尚未确定：有具体依据的机制〕；该机制使用〔合法训练阶段可获得的信息〕，在相同候选、监督和预算下，相对普通融合、简单频次校正及接近的学习融合方法改善〔事先确定的准确率取舍〕。

不能用“自适应”“可靠”“协同感知”填补机制空格。仅把λ从1改为0.75也不构成新方法贡献。与此同时，也不要求有价值的方法必须更大、必须改骨干，或每项指标都胜过自己所有历史版本。

## 5. 下一项工作的范围与退出条件

**先给一个工作日完成贡献论证，不再承诺一轮新训练就能找到创新。** 交付物是一页可被反驳的机制说明：具体失败现象、拟解决原因、为什么既有简单方法不足、与最近工作的实质差异，以及能否定该机制的最小对照。

顺序固定如下：

1. 今天已完成：同候选双域固定权重曲线及最近工作重合核查。它排除了“只要组合比原GRAM高就够了”的过宽贡献标准，也发现了当前固定配置的局限。
2. 接下来的首项：核查候选机制所需的监督是否能在合法训练划分中构造，并说明它如何解释两域差异。旧训练事件暴露、calibration与未来验证不一致已经是已知风险，不能再只凭训练内部loss下降申请大规模实验。若所谓新信息仍只是旧36项分数/流行度统计，不重新训练已失败的门控；新的信息来源或监督目标必须具体写出且可检查。
3. 只有第二项提供可检验机制后，才冻结一次最小原型：同样的B1分数和候选，比较普通融合、简单频次校正、匹配容量的普通学习融合与研究改动。首先看研究改动是否超出这些对照，而不是只超过旧B1固定点。参数选择不得用同一验证结果反复挑选后又当独立成绩；不读取新test来指导设计。
4. 若差异只剩调权重、换名称、更多训练，或没有可信的训练监督，就判定这一贡献候选不足，停止该候选。届时应调整论文定位/范围，而不是恢复蒸馏、门控或新架构矩阵。分析型论文属于另一种定位，需用户目标允许且有新的可推广结论，不能自行把方法论文换成负结果合集。

H0旧收益归因继续后置；本轮缓存权重曲线没有训练旧目标，也不等于恢复H0。大实验仍按用户要求后台运行、通过artifacts/status查看；本轮没有启动任何大实验。

统计解释11项核查：已并列两域、总体与低频（辛普森风险）；按用户评价（生态谬误）；保留未覆盖目标（选择偏差、碰撞变量、幸存者偏差）；明报分组人数和H10（基率）；比较相同冻结分数（均值回归风险仍不能代替独立重复）；完整保留168设置及开发集选择性质（多处寻找、分叉路径）；不以曲线识别唯一成因或反向因果。整体等级CAUTION，未做新确认性检验。
