# 固定低频位置重排：机制论证、结果与投入判断

日期：2026-09-17。Origin Skill：academic-research-suite。对应用户“继续”，完成上一轮约定的具体机制论证、低成本否证和去留判断。

**结论：停止这份固定位置重排配方的扩展，不将其定为论文新方法。** 它能精确保住所有低频候选的名次，但没有形成预先要求的双域总体改善；已有约束排序研究也使这项简单规则不足以独立支撑方法新颖性。Beauty的正结果保留，不能据此只选成功数据域。当前B1＋PCRF继续保留，新的论文主体仍未确定。

**一页机制论证**

| 必答问题 | 本次给出的具体答案 |
|---|---|
| 要解决什么 | 加强协同融合可以改善非低频目标排序，同时损害低频目标；能否保护已有低频成绩，并利用剩余排序自由度提高总体准确率？ |
| 可反驳的假设 | 固定当前B1＋PCRF中每个低频商品的绝对位置后，普通协同融合仍能在其他商品内部提供有效排序信息，而且两个域都受益。 |
| 实际操作 | 按训练频次标记候选；保留低频商品身份和名次；将其他候选按固定权重普通融合重新填入剩余位置。无需训练新模型。 |
| 合法输入 | 固定候选50、B1原始分数、已有CF分数、训练频次。排列函数不接收目标、目标频次或验证标签。 |
| 确定性性质 | 每个被保护商品名次恒等；任何低频目标的Hit/NDCG均不变。候选外目标仍为零。不能保证总体成绩上涨。 |
| 最小否证 | 当前方法、普通融合、简单频次校正、只固定组别位置、固定低频商品、固定非低频商品，共六臂；两域完整开发集。参数在结果前固定。 |
| 实测回答 | 低频保护恒等式成立。总体N10：Toys −0.2093%，Beauty +0.8416%；Top10命中净变化 −10/+27。假设中的双域改善没有获得支持。 |
| 创新性判断 | 受约束排序、组别配额、参考排名保持均有先例；本次没有新增有效估计器、求解算法或可推广证据。不能把位置恒等式包装成新定理。 |
| 投入决定 | 不扩到更多seed、不按结果改分组/权重、不给它追加门控或重新训练。保留为诊断对照。这个决定针对当前配方，不否定所有受约束排序方法。 |

这次没有完成“找到一个足够强的新方法”，完成的是对一个具体、可实现的机制的判定。Beauty的约0.84%提升是真实的开发集点估计；Toys的小幅下降也不证明所有总体收益都必然以低频损失换取。停止投入同时考虑了预定结果门槛、与简单对照的关系和现有方法重合，不能把门槛解释为任何论文都必须满足的发表标准。

这里普通融合的权重始终为1；与上一轮“开发集上选出的最佳权重”不是同一个设置。简单频次校正也固定权重1、频次系数0.5。阈值沿用旧值Toys≤5、Beauty≤6，不据本轮结果修改。

这组控制进一步限定了问题：Toys普通融合对非低频目标的N10提高2.2290%，但限制它只能在原有非低频位置里重排后，变为下降0.2594%。因此，原来的非低频收益并非全都来自组内顺序改进；跨组位置变化是相关因素。Beauty限制后的非低频N10仍提高0.9533%。这是固定缓存上的机制对照，不是关于真实用户行为或曝光偏差的因果结论。

只固定组别位置也明显减轻了普通融合的低频损失，但它不能保护每一个低频商品：Toys低频Top10净少7个，Beauty净多1个。精确固定低频商品则逐项保住名次，同时也禁止这些商品得到提升。不能把“损失为零”说成“低频推荐能力提高”。

事后另做2,000次按用户配对bootstrap，主臂全体N10绝对差的逐项95%区间为Toys [−0.00076868, +0.00042718]、Beauty [+0.00004422, +0.00114575]。它们仅描述本次固定预测的用户抽样不确定性，未校正开发集反复使用、跨方案比较或研究路径选择，也不包含训练seed波动；不据此宣称确认性显著提升或Toys与当前方法等价。

本次说明：旧calibration高分不足以成为再训练一个自适应融合器的投入依据。此前CF事件排除和未见交互筛查也未得到所需总体收益，不能由本表直接推出“现在必须整链重训”。原停止决定及成本判断不变。

**分数机制：可以解释公式，不能据此创造新颖性**

令g、c、p分别为候选内标准化后的B1分数、CF分数和log(1+训练频次)，r为旧可靠性。当前分数可重写为：

`g + r·z(c−0.5p) = g + αc − 0.5αp`，其中`α=r/std(c−0.5p)`。

两域41,775个用户、全部候选上的等价误差最大2.67e-15。α的10%/50%/90%分位，Toys为0.5781/0.8533/1.1144，Beauty为0.5273/0.8087/1.0633。由此可见，r之外的再次标准化也改变了实际协同系数，而且协同系数与频次扣分系数被绑定。这是代数事实；它没有证明绑定就是泛化失败的唯一原因。仅拆成两个自由权重仍属于简单融合对照，不能直接算新贡献。

**论文投入判断与下一步边界**

目前能支持的是“协同融合存在总体与低频排序的取舍，简单规则在两个域上的表现不同”；缺少的仍是一个相对简单强对照有独立价值、能够被可信监督支持的新机制。本次硬约束没有填上这个空格。现有B1＋PCRF的有效结果保留，但不能靠这次分析、换名字或更多seed补成尚未成立的核心创新。

我的建议是结束这条配方的技术投入，并以本页首段的一页论证做一次论文范围决策。若CCF-B方法贡献要求保持，则目前没有证据支持承诺9月底能冻结新方法；若完成时间优先，需要与导师重新确认可接受的贡献范围和投稿定位。这个目标取舍不能由助手把方法论文自动改成分析论文，也不能用继续堆实验掩盖。**就目前已核查的候选，没有充分依据自动启动下一项大实验；需要先有不同于已失败配方的实质依据。**

保留既有研究资产；不恢复旧36项统计门控、H0旧收益归因、整链留出重训或商品顺序迁移。后续若有满足投入条件的实验，仍遵守后台执行、通过artifacts/status观察的偏好。
