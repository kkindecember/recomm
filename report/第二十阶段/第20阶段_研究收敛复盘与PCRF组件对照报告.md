**已成立的结果：PCRF整体相对原GRAM的收益已通过双域、多item-head seed及两域各一次冻结test确认。** Toys/Beauty × seed2023/2024/2025的六个validation单元，Hit@10、NDCG@10和tail Hit@10增量全部为正。Toys test Hit@10相对提升约7.95%，Beauty约5.94%，两域配对增量95%区间均高于零。多seed改变的是item-head，GRAM父模型固定；多seed结果来自validation，不能写成六次test。来源：[双域多seed](../第九阶段/GRAM_第九阶段_P9-S双数据集多Seed稳健性验证报告.md)、[Toys test](../第九阶段/GRAM_第九阶段_CF0-B5_P9-2E冻结PCRF独立Test确认报告.md)、[Beauty test](../第九阶段/GRAM_第九阶段_P9-X%20Beauty跨数据集外部确认报告.md)。

## 1. 本次新完成的固定组件对照

Toys原validation共19,412人；使用第20阶段同精度父模型beam50，固定item-head seed2023。零新训练、零GPU、执行84.65秒。所有输入前后SHA一致，原GRAM和完整PCRF逐用户rank均与原参考精确一致。

|---|---:|---:|---:|---:|
| 原GRAM | 0.076231 | 0.119153 | 0.058333 | 0.091860 |
| 候选内CF独排 | 0.065820 | 0.110293 | 0.027591 | 0.048643 |
| 普通融合 λ=0.75 | 0.078519 | 0.123738 | 0.050582 | 0.082752 |
| 普通融合 λ=1 | 0.078001 | 0.123532 | 0.047740 | 0.078876 |

| 完整PCRF | 0.078679 | 0.125232 | 0.058435 | 0.093217 |

低频组固定为训练频次≤5，共5,160人；所有方法共享同一个候选集合，Hit@50均为0.212085。这里只检验候选内排序，不检验召回改善。

主比较为完整PCRF对λ=1普通融合，不按结果选择更弱的普通融合基线。
- PCRF对原GRAM：NDCG@10绝对变化+0.002448，描述性95%区间[+0.001447, +0.003505]。
- PCRF对同权重普通融合：NDCG@10绝对变化+0.000678，描述性95%区间[-0.000165, +0.001454]。
- PCRF对既有λ=0.75融合：NDCG@10绝对变化+0.000160，描述性95%区间[-0.000622, +0.000879]。
- PCRF对仅可靠性权重：NDCG@10绝对变化-0.000152，描述性95%区间[-0.000928, +0.000569]。

### 数据支持什么

1. PCRF相对原GRAM的NDCG@10约+3.21%，整体正收益再次复算成立。但这复用了父预测和已经多次开发的validation，不是新独立确认。
2. 普通融合已解释相当一部分整体增益。PCRF相对同权重普通融合的总体增量区间跨零；相对既有λ=0.75融合仅+0.000160，不能把PCRF描述为大幅优于所有简单融合。
3. 流行度校准最清楚的作用是修复低频伤害：普通λ=1融合的低频NDCG@10为0.047740，完整PCRF为0.058435，差+0.010694，描述性95%区间[+0.009019,+0.012393]。相对原GRAM低频0.058333主要是恢复原水平，不能写成对原模型显著改善尾部。
4. 仅可靠性权重的总体NDCG@10点估计0.078831略高于PCRF，但低频只有0.050981，明显低于原GRAM。不能因为一个总体点估计较高就替换PCRF，也不能宣称各组件单独加入后所有指标都上升。
5. CF候选内独排NDCG@10仅0.065820，弱于原GRAM。合理的工作假设是协同分数与生成分数互补，需要校准使用；这不证明某种表示机制是唯一原因。

## 2. 三个月流程中可改进的地方

| 已有证据 | 对工作方式的含义 |
|---|---|
| 多阶段在模型/编码替换时先大幅损失GRAM能力 | 优先保留强父模型。换架构前，单独估计编码和初始化代价。 |
| BW1 beam200覆盖增加约12–13个百分点，但Hit@10未改善 | 候选覆盖是诊断量，不能作为推荐增益的替代。 |
| CF1-C2全量候选校准也未超过PCRF | 新的校准想法必须说明与旧union/候选准入的区别，不能只换名字重跑。 |
| PRPD、GACR等早期整体弱正同时存在尾部/深截断负向 | 探索阶段报告取舍；确认阶段再要求预定稳定性。不要事后更改旧实验判定，也不要把所有弱正统称无效。 |
| 小代理、短探针、完整训练混杂在历史路线中 | 分开记录“代码工作”“当前预算未见收益”“完整配置负面”，不能用一次小探针否定整类方法。 |
| PCRF的3个seed是item-head seed，GRAM父模型固定 | 后续若需要声称对骨干训练随机性稳健，必须补骨干seed；已有结果不能冒充该证据。 |
| validation长期重复开发，Toys test已有历史消费 | 不再把重新分折当全新独立确认。最终确认应冻结方法、明确未消费的数据范围；本次不新读test或Sports。 |

这些是对现有记录的工作诊断，不是对个人动机、努力程度或能力的判断。后续辅助工作也应减少“跑完一个方法再找下一个”的惯性，每次新增实验先写清它能排除哪一种解释。

### 2.1 GACR改动规模与已经执行的教师设计

GACR-v6在冻结既有C1骨干后，新增训练的是6→16→1残差排序器，共129个参数；输出为有界残差，使用target-vs-hardest-negative hinge loss。C1本身此前已接受词法CE与catalog头训练，因此129不是整条C1/GACR路线累计训练的参数量。v6相对v3的唯一预定改动是用完原fit split的训练records，结构、损失和30次full-batch更新不变；不能将其写成新骨干结构或新损失设计。

历史两域各1,024人缓存复核中，三组残差seed的NDCG@10相对未经C1训练的原GRAM：Toys约+1.93%～+2.34%，Beauty约+3.50%～+3.84%；但相对固定seed2023的原PCRF低约4.14%～4.65%。这是不同模型/数值流程的历史配对缓存比较，尚非本次全量、同精度组合结论。结构改动小和收益有限是当前事实，不能据此承诺GACR已成为超过PCRF的新主方法。

PCPS实际目标为`L = CE + alpha * (0.5 * prefix_loss + 0.5 * full_path_loss)`。其中PCRF参与困难前缀负例选择，校准CF和可靠性参与路径权重；它不是直接拟合完整beam50的教师概率分布，但明确属于已经做过的教师引导生成。代码中的CF并非虚接：3,490个训练节点中，真实CF与普通机制的负例集合仅1,098个完全相同。

## 3. 下一步优先级与具体实验

**当前主线建议：研究如何在保留生成排序能力的同时，有条件地使用协同信息。** 这是由PCRF正结果、普通融合尾部伤害和偏好更新退化共同提示的研究问题，尚不是新颖性已经验证的方法。

| 优先级 | 任务 | 作用与决定 |
|---|---|---|
| 已完成 | 本次7臂CPU消融 | 将“PCRF有效”细化为“普通融合提供总体增益，校准主要修复低频伤害”。 |
| 正在运行 | SFT全量、GACR/PCRF组合、SPRec收尾 | 先判断是否存在独立于PCRF的新收益，保持当前协议。 |
| 辅助工作，当前不优先启动 | Beauty固定相同7臂消融，复用validation候选及冻结head，不调权重 | 用于细化组件归因，既不是确认PCRF整体有效的前提，也不能补上论文核心贡献缺口。此项尚未启动。 |
| 有组合增益时 | GACR组合的冻结跨域及残差seed验证 | 优先确认现有正结果，而不是立即加新结构；C1来源单独控制。 |
| 已撤回的泛化建议 | 将“CE＋PCRF教师”直接列为新训练方向 | 与已执行PCPS存在实质重叠；历史核验已完成，当前无新训练计划。未来候选必须明确与旧损失、教师作用位置及训练条件的差异，解释其针对哪项旧失败证据。 |

此次没有找到“完整beam50教师概率分布蒸馏＋全量GRAM训练”的已完成记录，但这种具体实现差异本身不是启动理由。若以后形成有实质区别的教师方案，仍须使用合法训练前缀、冻结校准参数、保留frozen parent与等预算CE对照，报告真实beam指标；PCRF的标准化依赖完整候选集合，不能将少量负例上的重新标准化冒充原beam50教师。旧探针不支持继续训练后的保真性已解决，不能跳过这一点直接增加训练时长。

探索可以有小范围、有依据的超参数选择，但必须明确开发集、预定预算和全部结果，选择后再冻结确认。短小样本用于发现工程错误和强退化，不能仅凭CI跨零就否定可能只有1%左右的效果。

## 4. 新颖性不能靠命名保证

本轮定向核对了[UniGRF（SIGIR2025）](https://arxiv.org/abs/2504.16454)，其已使用排序驱动的生成增强；以及[SmartGR（2026-08预印本）](https://arxiv.org/abs/2608.02048)，其包含beam-aware ranking distillation。因此“把排序蒸馏回生成器”“保留原模型再加一个辅助损失”本身不能算未被研究的贡献。本项目若采用，需要证明具体适用条件、与简单教师/CE对照的差异及收益。当前检索只用于排除宽泛的新颖性声明，不是完整文献综述。

PCRF可以作为方法基础，但不能保证其现有复杂度和增量足够发表；也不能把重排方法自动视为没有价值。应以同类工作的直接对照、机制消融、跨域和成本证据判断。

## 5. 执行与统计边界

首次尝试在评分前因误要求历史tail_mass元数据与新beam一致而失败，产物保留。v2按实际候选重算；发现150名用户的历史元数据不同，最终19,412名用户的raw/PCRF rank全部精确对齐。工程修正没有改变任何消融参数、候选或评估用户。

覆盖11/11统计谬误检查：总体/低频与非低频同时报告，避免聚合掩盖；逐用户配对，避免生态推断；不按新结果筛选用户，保留全体和分母；未按极端案例选样，仍承认历史选模乐观偏差；全部7臂和首次工程失败保留；多项比较未校正，CI仅描述；方案在新消融指标计算前固定，但所用validation已长期开发；不作线上因果或反向因果推断。用户bootstrap不能代表训练seed不确定性。

本次CPU不改变任何正在运行的训练或评估。无新GPU任务、无test读取、无参数搜索、无自动发布新结果。
