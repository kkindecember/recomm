# 共享 GRAM 表示替代 CF：首轮结果与失败定位

2026-09-18。状态：**COMPLETED；缓存前向与排名独立复算 VERIFIED。停止当前配方扩展。** Origin Skill：academic-research-suite / experiment-agent，单会话执行。这里的复核指重新加载 checkpoint 做 CPU 前向及独立计算排名，不是重新训练复现。

本轮把之前建议落实为代码并跑完：冻结 C1、B1、softmax 小头及原50候选，用 GRAM 历史提示表示、C1 自有商品向量及原6项特征，训练评分头替代三个外部CF的平均增量。没有修改生成器，没有新beam，没有读取test。

结果否定了本轮固定配方的采用价值；不能因为小样本能拟合，或优于普通CE头，就认定内化成功。当前仍保留 softmax.mean 为 NDCG 优先时的最强效果参照；原 normalized.next_only.mean 的登记和历史结果没有被覆盖。

## 全体开发用户结果

Toys，19,412名用户，固定原候选。教师采用预先指定的原小头 seed20260917，学生 seed20260918；这是单实例对照，不是原三小头平均指标。未覆盖正确目标的用户照常计入分母。

|---|---:|---:|

迁移臂相对完整教师 NDCG 下降10.6899%，Top10净少304个命中；相对同一无CF版本 NDCG 下降2.9738%，净少64个命中。外部CF的原NDCG增量为0.00696705，新头相对无CF的增量为−0.00239803，因此增量保留率为−34.42%，不是接近原总分就算保住了协同能力。

低频目标组 NDCG：教师0.06278221、无CF0.06023221、迁移0.06158058。迁移虽高于该组无CF，却未满足对教师最多下降0.0005的预定保护门。非FIT用户组同样未获益：教师0.08773600、无CF0.08113117、迁移0.07886002。

预定四项继续门：增量保留至少80% **未过**；NDCG高于普通CE **通过**；Hit下降最多0.001 **未过**；低频NDCG下降最多0.0005 **未过**。因此停止当前配方，不启动Beauty、多seed、延长轮数或学习率网格。

## 这次具体学到了什么

**128用户的小样本检查能够学会。** 400步后，教师增量MSE由零输出参考的0.831568降至0.000213，下降99.974%；最终列表Top10重合99.22%，教师希望升降的商品关系满足99.89%。这排除了本接口在这批小样本上完全无法表达或优化的解释；它不能证明一般可学性或泛化。

**扩到6,884条训练前缀后，完整拟合与迁移仍不充分。** 两正式臂各10轮、540次更新，从共同初始权重重置，不继承小样本过拟合权重。迁移臂训练平均MSE相对零输出下降49.76%，训练Top10重合67.12%；校准重合60.20%，全体验证重合59.52%。训练教师NDCG为0.70138，学生只有0.41666，无CF为0.38509。故不能把失败简化为“教师已经完全学会，只是泛化不好”，完整训练自身也只承接了部分教师能力。

**分数更接近不等于有效排序改善。** 验证MSE相对零输出下降25.27%，但教师指定的关键升降关系只满足41.98%，最终推荐指标低于无CF。这是当前记录支持的现象，尚未确定是表示瓶颈、有限训练预算、冻结商品向量、点级拟合目标，还是受限训练前缀与部署分布共同造成的。

因此，上一条“共享表示＋评分头”建议应更新为：它的接口可行、少量样本可拟合，但这份直接替代CF的实现没有获得可用机制。不能以“再加注意力”“多训练一点”自动接续。若以后重新研究，首先需有一个能够区分上述解释的受控诊断，而不是再把架构复杂度当作贡献。

本轮只使用历史提示第一passage的平均表示，不代表完整GRAM编码token、细粒度商品passage或所有共享表示设计都已被否定。旧历史注意力实验与本轮也不能合并成对所有内部建模的结论。

- 新评分头164,609个可训练参数，C1及商品表冻结。7项基础检查通过：零分支恒等、候选置换、可靠性为零恒等、输出中心化、普通CE一致、非整除分块梯度一致、排序诊断正对照。

- 首次prepare在候选列顺序不一致处停止，新增训练0步。修正为逐用户、逐商品ID对齐；修正前源码与错误保存在 `artifacts/phase20/shared_cf_probe_toys_v1_prepare_failed01`。没有改训练目标、预算或门槛。
- 修正后prepare约34.25秒，GPU完整run约120.91秒；共400个小样本更新及2×540个正式更新。GPU共享负载下的运行时间只表示本次任务耗时，不是公平端到端效率比较。
- 冻结C1权重在训练前后哈希一致，输入及输出哈希检查通过。75份源码/配置/协议快照保存在运行目录。训练与calibration新头用户互斥，历史记录和目标逐条核验。
- CPU重新加载三个checkpoint复算，最大分数误差2.03e−6；用独立稳定排序实现重算106,208条排名，均与保存结果一致。没有重新训练，也没有声称单初始化结果显著。
