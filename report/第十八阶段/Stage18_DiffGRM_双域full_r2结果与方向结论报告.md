## 1. 方向结论

**当前 DiffGRM 配置在两域均明显低于 GRAM，没有得到提点信号，建议归档并降低投入优先级。** Toys 完整验证 NDCG@10 相对下降 **53.93%**，Beauty 下降 **36.18%**；同用户配对区间也完全位于负侧。这足以支持当前以“尽快寻找新提点方向”为目标的资源决策。

**这不能写成“扩散机制本身被证明无效”或“已经排除训练不足”。** 两域上限均为 200 epoch，实际因 patience 分别停在 110 / 160；尤其 Toys 的 warmup 很长，停止时学习率仍为峰值的 94.17%。现有实验没有把充分低学习率训练、SID 表示、模型容量和解码策略等因素逐项隔离。继续跑能否回升仍未知，更没有证据保证能追上 GRAM。

已准备的 Beauty `full_r3` finish 方案只完成 CPU 恢复检查，optimizer updates 为 0，**没有启动训练，也没有新的模型结果**。本次补报告不追加旧方向训练。当前推进 ETEGRec 的优先级保持。

本报告的 DiffGRM 是作者原生扩散生成推荐路线；DIFF→GRAM 是属性 / 序列融合迁移，两者机制不同，后者结果单列在 [DIFF→GRAM 最终报告](Stage18_DIFF_GRAM_双域full_r2结果与方向结论报告.md)。

## 2. 实际运行了什么

采用本地固定的作者 DiffGRM 代码，commit `238911435b6ca4f576d0b4d943359b98c865c172`。使用作者扩散后端、guided masking 和语义 ID 生成流程，在本项目的数据划分、训练转移及 item 指标接口上适配；这是本地任务迁移，不是对作者论文原始数据与全套训练条件的独立复现，也不是在已有 GRAM checkpoint 上加一个扩散辅助损失。

| 设置 | Toys | Beauty |
| --- | ---: | ---: |
| 训练转移 / validation 用户 | 109,361 / 19,412 | 131,413 / 22,363 |
| 目录商品数 | 11,924 | 12,101 |
| encoder / decoder 层数 | 1 / 4 | 1 / 4 |
| hidden / heads / FFN | 1024 / 8 / 1024 | 256 / 4 / 1024 |
| 最大历史长度 | 50 | 50 |
| 有效 batch / microbatch | 1024 / 32 | 1024 / 128 |
| 峰值学习率 / warmup steps | 0.003 / 10,000 | 0.01 / 10,000 |
| 原生 beam / 返回 item 上限 | 256 / 50 | 256 / 50 |

语义 ID 使用 Sentence-T5 表示和 OPQ 编码。模型架构、历史长度及 beam 与历史 GRAM 不完全相同，因而本报告比较的是实际候选效果，不能将差异归因于单一扩散算子。具体配置见 [Toys](../../experiment/phase18/config/s18_diffgrm_native_toys.json)、[Beauty](../../experiment/phase18/config/s18_diffgrm_native_beauty.json)，执行适配见 [s18_diffgrm_native.py](../../experiment/phase18/protocol/s18_diffgrm_native.py)。

## 4. 实际预算、停止点和“训练够不够”

| 数据集 | 接续源 epoch | 新增 / 实际总 epoch | 选中 epoch | optimizer steps | 停止原因 | full_r2 墙钟 / 其中最终完整验证 |
| --- | ---: | ---: | ---: | ---: | --- | --- |
| Toys | 19 | 91 / 110 | 60 | 11,770 | patience = 5 | 11.61 小时 / 23.38 分钟 |
| Beauty | 33 | 127 / 160 | 110 | 20,640 | patience = 5 | 3.79 小时 / 9.23 分钟 |

以上墙钟取自各 `full_r2/result.json`，包含本次接续训练与评估，不包括此前准备、原始训练及其他分支；也不是扣除共享 GPU 干扰后的纯 GPU 计算时间。Toys 于 09-09 03:54、Beauty 于 09-08 19:21 完成（北京时间）。

- **Toys 日程边界较强：** 每轮 107 次更新，warmup 约在 epoch 93.46 结束；epoch 110 停止时 LR = **0.0028250677**，仅走过 warmup 后余弦区间的 15.53%。最佳子集在 epoch 60；后续 70 / 80 / 90 / 100 / 110 连续 5 次未刷新最佳，其中前三次仍处于 warmup。因此“patience 已触发”等同于“充分低 LR 收敛”的说法不成立。
- **Beauty 的平台证据更充分，但也未到 200：** 每轮 129 次更新，warmup 约在 epoch 77.52 结束；epoch 160 LR = **0.0024087312**，为峰值的 24.09%，走过 warmup 后区间的 67.34%。子集 NDCG@10 在 epoch 90 / 110 / 160 分别为 **0.043686122 / 0.043758903 / 0.043704217**。没有持续缩小与 GRAM 差距的轨迹，但剩余 40 epoch 效果未经验证。
- **轨迹来源不同：** Toys 保留已完成的短日程模型、Adam 与 RNG 状态，用一个 epoch 的学习率桥接后进入长曲线；不是从头按原始长日程连续训练。Beauty 则从原始 epoch 33 恢复原日程。不能笼统把两者都称为作者原始训练完全复现。

所以，对“继续跑还有没有空间”的准确回答是：**有未排除的回升空间，Toys 尤其如此；没有证据支持继续跑就能达到提点目标。** 目前归档依据是大幅落后、既有投入和用户目标的机会成本，而不是完成了对所有训练日程及全部扩散机制的否证。

## 5. 分组与统计边界

以下为 NDCG@10 相对同组 GRAM 的绝对增量；历史长度统一按已有基线缓存的最多 20 项分组。Tail 阈值来自冻结参照，Toys target frequency ≤ 5，Beauty ≤ 6。

| 分组 | Toys 人数 / 增量 | Beauty 人数 / 增量 |
| --- | --- | --- |
| 历史 1–5 | 12,673 / -0.042703396 | 14,063 / -0.022102548 |
| 历史 6–10 | 4,319 / -0.038889203 | 5,311 / -0.021919989 |
| 历史 11–20 | 2,420 / -0.036902137 | 2,989 / -0.032928831 |
| Tail | 5,160 / -0.047198285 | 6,049 / -0.014834646 |
| Non-tail | 14,252 / -0.038935071 | 16,314 / -0.026721509 |

上述组均为负，不能靠只挑某种用户把整体负结果改写为成功。组间差距仅作描述，未作组间机制显著性检验。

配对分析固定 checkpoint 和 seed，以用户为单位有放回重采样 2,000 次，随机种子 2023，取 percentile 95% 区间。共享分析共产出 **4 候选 × 2 参照 × 3 指标 = 24 个未作多重校正的区间**，不输出显著性发现清单。它们不包含模型选择、训练 seed 及共享商品依赖的不确定性；全量 validation 包含用于选模的 2,000 用户，且已有开发历史，因此不是独立 test 确认。

统计误读检查 **11 / 11**：

| 检查项 | 本次处理与剩余边界 |
| --- | --- |
| Simpson 悖论 | 固定用户权重，历史长度 / tail 分组均为负；未发现这些分组导致的整体反转。 |
| 生态谬误 | 分析单位为用户，不将域均值推断为每个用户都受损。 |
| Berkson / 样本选择 | 结论限于既有筛选目录和验证人群，不外推所有用户与数据集。 |
| Collider bias | 不按模型是否命中筛用户；分组使用已有历史长度和目标频次。 |
| 基率忽视 | 同时报告基线分数、人数、净得失，而非只报相对百分比。 |
| 回归均值 | 披露子集选最佳及完整集合重叠，不把最佳子集值当总体效果。 |
| 幸存者偏差 | 两域全部用户纳入；不足 50 的列表不删除，历史较好短分支亦披露。 |
| 多处寻找效应 | 两域及三主指标同时报告；区间未校正，不作确认性显著结论。 |
| 分析路径自由度 | 披露 screen / full 分支、学习率桥接与提前停止；结论为探索性。 |
| 相关与因果 | 无匹配容量、预算、表示及解码消融，不归因于扩散本身。 |
| 反向因果 | 当前分析仅读取历史训练来源记录和 validation，不构造未来训练因果论证。 |
