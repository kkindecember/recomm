## 1. 当前判断

**值得继续有限验证。把 DIFF→GRAM 保留为当前已有实验中最值得核实的增量候选，优先完成已授权的 Beauty 固定日程复核；暂不扩大为两域、多参数长训。**

这个判断来自 DIFF→GRAM 自身的小幅同向信号与较小整体退化，不是因为其他候选失败就自动让它有效。当前尚未确认稳定提点，也不能承诺延长训练后会达到某个提升幅度。

## 2. 为什么值得保留

1. Beauty 六项汇总指标均为正增量；Hit@10 净增 23 人，Hit@50 净增 14 人。它没有出现 ETEGRec / ReaRec Beauty 那样约 24%–27% 的整体 NDCG 退化。
2. Beauty 的增量不只出现在选模子集：2,000 人子集 NDCG@10 增量 +0.000393730，子集外 20,363 人为 +0.000379627；短、中、长历史和长尾/非长尾分组点估计也均为正。各组并非独立复现实验，子集外仍是 validation。
3. Toys 的整体变化较小，并有明确取舍：短历史和长尾组点估计正，中长历史和非长尾组负。这支持保留调查空间，但不能只挑有利分组宣称成功。
4. 它直接保留原 GRAM 词法生成骨干，通过 DIFF 属性/历史分支追加 encoder memory，符合当前寻找 GRAM 内部增量、后续再与 PCRF 组合的目标。

比较边界：DIFF→GRAM 从强 GRAM parent 出发并继续训练；ETEGRec / ReaRec 是不同的独立候选。接近 GRAM 可能部分来自保留强骨干，不代表 DIFF 机制天然优于另外两篇论文，也不单独证明新分支发挥了有效作用。

## 3. 目前还缺哪几块证据

- **稳定性**：Beauty 只得到一次探索性的弱正结果；六个相关指标同向不等于六次独立成功。当前固定日程复核仍是 seed2023，也不能代替多 seed。
- **归因**：没有相同父模型、数据、优化器日程和选模规则下的纯 GRAM 续训对照，无法区分“额外训练”与“DIFF 结构”的增量。
- **组合价值**：DIFF→GRAM + PCRF 未评估。Beauty DIFF→GRAM 的 0.065354591 低于 GRAM + PCRF 的 0.067907682，但这并不能回答组合后的增量。
- **跨域**：Toys 的点估计很接近零，但统计上尚未建立非劣性；它也存在子集略涨、全量略降的现象。

因此可以把它当作值得继续验证的候选，尚不能把它写成已确定的论文方法或已确认提点方向。

## 4. 最小且有决策价值的后续顺序

### A. 完成当前 Beauty 固定日程复核

现有任务从原 Beauty epoch25 GRAM parent 出发，重新初始化 DIFF 分支与 Adam，同 seed2023，预先固定 1 frozen + 10 joint。它检验去掉短档接续/学习率桥接后能否再次得到正信号；原 full_r2 已经是全量训练数据，本次主要修正日程，不是从小样本升级全量。

用最终完整 validation 同时比较原 GRAM 和旧 DIFF→GRAM。若 NDCG@10 / Hit@10 仍同向正，保留“固定日程复现正信号”；若接近零、反向或只在选模子集上涨，降低优先级。不要因早期曲线修改预先冻结的 11 轮日程，或连续追加轮数追逐正值。

### B. 检查冻结 PCRF 的增量能否保留

这是当前最贴近实际方法目标的组合检验，优先利用已保存的 DIFF→GRAM 候选和 sequence scores。固定已有 PCRF：lambda=1.0、beta=0.5、gamma=1.0，长尾阈值沿用历史规则。

应完整列出四臂：GRAM、GRAM+PCRF、DIFF→GRAM、DIFF→GRAM+PCRF。关键是比较 **DIFF→GRAM+PCRF 与 GRAM+PCRF**，不能仅证明组合超过裸 GRAM，也不能把历史 PCRF 增量直接加到新候选分数上。

本次只完成代码/文件可行性检查，没有执行组合：候选保存的是 length_penalty=1.0 的序列分数，PCRF 在每人的实际候选内标准化序列、CF 和频次分数。必须验证长度/分数口径、商品映射和排序身份。新候选需要对应的 CF 分数及训练前缀频次；历史 per-user.tsv 只有最终 rank，不足以还原组合。原 PCRF 入口会读含 test 的原始 user_sequence，后续应使用已冻结 prepared train/validation 的专用入口，不能直接照抄旧命令。

若能复用对应的 CF 得分缓存，优先离线处理；若必须额外调用冻结 item-head 评分，需明确这是新增评分、评估其成本，不能声称只是把已有两个 rank 相加。现阶段不重训 GRAM / PCRF。

### C. 有重复正信号和组合价值后，再做归因与跨域

再安排最小的匹配 GRAM 续训对照，以及有针对性的结构/属性消融；这一步关系到能否把增量归因于 DIFF。候选继续成立后，再做 Toys 的固定日程和多 seed。当前用户希望先复用历史基线，所以不在信号尚弱时启动完整基线重训矩阵。

如果有改善只来自纯 GRAM 续训，或组合没有超过 GRAM+PCRF，应如实缩小方法主张，不能把训练预算或 PCRF 的已有收益当作 DIFF 的贡献。若增量持续落在噪声范围，也不反复换 seed、挑指标或群体来筛出正结果。

## 5. 关于进一步改结构

现在没有证据支持立刻扩大 DIFF 层数、网格搜索 cutoff / alpha 或提高辅助损失权重。当前 loss 为 generation + 0.1×item_CE + 10×alignment，单看系数大小不能认定辅助项主导梯度，需结合实际损失与梯度再判断。

Beauty 有 categories+brand，Toys 只有 categories，且 cutoff、alpha 等不同；这与属性利用差异的解释相容，但尚无消融证明 brand 就是收益来源。若后续仍有信号，优先设计能检验具体假设的对照，而不是为了再试一条方向随意加模块。

小于 1% 的提升并非自动没有价值；是否值得成为方法取决于重复性、与强已有系统的增量、计算成本和归因证据。当前没有依据承诺能继续放大到 1%、3% 或更高。
