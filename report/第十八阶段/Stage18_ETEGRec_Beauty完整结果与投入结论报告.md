## 1. 结论

**当前 ETEGRec Beauty 适配没有提点，六项指标均落后于 GRAM 和 GRAM + PCRF。建议归档这轮 Beauty 配置，不继续同设置加时或补多 seed。**

完整 22,363 用户 validation 的 NDCG@10 为 **0.049127388**，GRAM 为 **0.064973703**，绝对差 -0.015846315，相对 **-24.39%**；相对 GRAM + PCRF 为 **-27.66%**。同用户配对区间完全在 0 以下，没有接近持平或弱正信号。

RQ 预训练、交替训练和固定编码微调都达到预先设定的最低训练要求并按平台判据停止，未触发 12 小时预算截断。最终选中 **joint_290 / joint_best.pt**；后续微调没有超过它。原始 result 中 `selected.phase=finetune, epoch=65` 是结束时的训练进度，不能误写成“最终选择 finetune 第 65 轮”。

结论只覆盖本地冻结 CF512 输入和当前训练/模型设置。ETEGRec 是独立编码/推荐候选，本次没有把机制单独嵌入原 GRAM，也没有完整复现作者原始数据和全部设置；负结果不能推广成联合编码学习机制无效。

“选模子集外”仍来自 validation，没有用于本轮逐轮选模，不应改称 test。分组彼此重叠；没有据此进行额外显著性搜索或筛选只报告有利人群。

## 5. 实现与比较的边界

直接使用固定作者 RQ-VAE 和推荐模型源码，本地 adapter 处理输入、训练日程、checkpoint 与目录约束 beam50。具体工程核验见启动报告；本次未修改运行中的共享 adapter 或 Toys runner。

主要设置与边界：

- 商品输入是已有 Beauty item-head 的归一化 512 维冻结向量，来自训练前缀及历史 validation 选模；它不是作者原始 SASRec 向量。
- RQ 用三位 256 码本加第四位消歧；推荐器为 encoder6 / decoder6、d_model128、4 heads，history20。
- ID / REC 交替，学习率分别 0.0001 / 0.005，按各自 update 计 warmup4000 / 8000；finetune LR0.0005。优化器为 AdamW，参数固定在配置中。
- 当前候选与 GRAM 的骨干、输入表示和训练路径不同。这次结果回答的是“这一独立候选是否更好”，不能隔离联合编码机制的纯贡献。
- 未跑多 seed、独立 test、同骨干消融或 ETEGRec + PCRF。没有正信号前，不默认追加这些实验。

## 6. CPU 复核与解释检查

复核覆盖输入/source/CF checkpoint 哈希、完整验证用户集合、历史长度、当前目标、合法且唯一 top50、分数有限有序、rank 和全部六项指标。对全部 **48 次趋势验证 + 1 次全量验证** 的保存预测重新检查；最佳 checkpoint 选择与原始 result 一致。交替 350 轮、微调 65 轮均完整覆盖训练前缀，原始配对区间重算一致，并补充相对 GRAM + PCRF 的配对区间。

历史参照 TSV 无 gold 列，历史目标身份依赖已有冻结输入/cache lineage；当前预测目标直接对照 prepared validation。CPU 复核通过不等于重新执行了模型，也不是绝对排除所有实现偏差。

统计解释检查 **11/11**：
