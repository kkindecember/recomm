## 1. 收尾结论

**本阶段没有找到已确认、值得继续扩大当前版本预算的 GRAM 增量。** DIFF→GRAM 的 Beauty 旧完整结果为 NDCG@10 相对原 GRAM +0.5862%，固定日程复核收缩至 +0.1791%，两次增量的用户配对区间均包含 0。Toys 旧完整结果为 −0.2389%；新长日程截至第17轮的最佳仍为第1轮冻结适配，尚无明显改善信号。

因此，按用户“收尾并另找研究方向”的本次决定，停止 Toys 长日程剩余训练、计划内最终全量验证及后续追加实验。**这是结合既有证据和投入成本作出的停止决定，不能写成已完整跑完21轮并证明失败。** 也不将小幅正结果改写为零收益，或将本地配置的负结果推广为整类方法无效。

名称需要区分：**DIFF→GRAM / Diff-GRAM** 是属性与历史融合模块接入 GRAM；**DiffGRM** 是另外一条原生扩散推荐路线。用户记忆中刚完成 Beauty、尚有 Toys 长训的任务是前者。原生 DiffGRM 的两个域此前都已结束。

固定复核的Hit@10新增107人、丢失93人，净增14人；去掉2,000名选模用户后，余下20,363人的NDCG@10差仍为微正（+0.000081215）。因此，不能说所有收益只来自选模子集。但固定复核没有放大旧信号，且缺少多seed及相同预算的纯GRAM续训对照；尚不能把微小差值归因于DIFF模块。

区间均为2,000次配对bootstrap：旧full_r2用seed2023，9月10日复核用seed20260910。它们固定了模型与验证用户来源，没有包含训练种子、模型选择和共享商品依赖，且未做多重比较校正。“区间包含0”既不确认提点，也不证明真实收益恰为0。

## 4. Toys长日程的实际停止范围

原计划从Toys epoch30 GRAM父模型重新初始化DIFF分支及Adam，固定1冻结+20联合，共21轮；有效batch128、microbatch4、FP32、beam50、seed2023。它不是从旧DIFF epoch11继续训练。

9月10日20:40:38发出停止信号，**20:41:07已确认训练及数据加载子进程退出**。训练此前从9月9日17:18:40运行，至本次停止约27小时22分；这是含共享资源影响的墙钟时间，不是纯GPU计算时长。

- 最后完整检查点：`last.pt`，epoch17、14,535次更新，含模型、Adam、scheduler及PyTorch CPU/CUDA RNG。

- 中断时原状态为epoch18，最近记录处理77,036/109,361条；这部分更新未另存，不能算入可恢复完整轮次。
- 未执行本轮最终19,412人验证；第19–21轮及剩余第18轮取消。无最终全量分数，不以epoch17子集替代。

Toys两个保留checkpoint在CPU成功加载、模型张量全部有限，文件大小/SHA及保存字段写入核验JSON。仅声称保留实际存在的PyTorch CPU/CUDA RNG；不补称保存了未包含的Python/NumPy RNG，也未执行恢复训练测试。

统计解释检查覆盖11/11项：

| 检查项 | 本次处理 |
|---|---|
| Simpson反转 | 披露已有分组取舍；本次不新增分组搜索 |
| 生态谬误 | 均值与新增/丢失命中分开，不声称每人受益 |
| Berkson / 样本选择 | 结论限于既有数据与筛选人群 |
| Collider偏差 | 不按是否命中筛人后重算总体效果 |
| 基率忽视 | 同时报分数、绝对差、相对差及人数 |
| 均值回归 | 保留子集选模与全量差异，峰值不当成稳定提升 |
| 幸存者偏差 | 已完成及提前停止的全部候选保留在账目中 |
| 多处寻找效应 | 多轮、多个候选和相关指标均属探索，未做确认性发现声明 |
| 分析路径自由度 | 旧桥接日程、新固定日程和本次用户停止分开记录 |
| 相关与因果 | 无匹配GRAM续训/结构消融，不能归因于单一算子 |
| 反向因果 | 不作行为因果推断；只描述离线模型表现 |
