## 1. 结论与投入决策

**当前 ReaRec 适配在 Beauty 上没有提点，六项指标均落后于 GRAM / PCRF；Toys 是主动截断的未完成筛选。降低当前方案优先级，不继续追加训练、跨域或多 seed 预算。**

Beauty 全量 validation NDCG@10 为 **0.047625009**，GRAM 为 **0.064973703**，绝对差 -0.017348693，相对 **-26.70%**；对 GRAM + PCRF 的相对差为 **-29.87%**。配对用户区间完全在 0 以下，支持当前 checkpoint 在这批用户上的负结果，不是接近持平的弱信号。

Beauty 已从最佳第 45 轮继续训练到第 150 轮，训练损失继续下降，验证效果没有超过原最佳。它完成了预定的最小训练预算和平台判据；现有轨迹没有提供“保持同设置继续加时会追回差距”的积极依据。没有跑满 300 轮，也不能据此证明任意更长训练、其他超参数或整个潜在推理机制都无效。

Toys 在当前资源决策下停止，不作为第二个完整负结果。目标是尽快寻找提点方向，不需要把每个不理想候选都跑齐双域来证明其无效。

## 2. 本轮具体比较了什么

本地模型直接使用固定作者 Transformer 与 ReaRec wrapper，保留隐状态回馈、推理位置编码和两次额外推理；PRL 包含末状态 CE、递进温度监督和噪声视图对比。warmup 无噪声时把原实现未初始化的对比损失设为 0，其他核验细节见 [Beauty 实现与启动报告](Stage18_ReaRec_Beauty实现核验与启动报告.md)。

本轮训练的是**独立 ID 序列候选**：商品 embedding 随机初始化并训练，未加载 CF 或 LLM 特征。它与 GRAM 的骨干、输入表征和打分方式不同，因此候选效果差不能被归因为“只加潜在推理就造成下降”。它也没有直接完成在 GRAM 内部接入同一机制的纯增量实验。

配置为 2 层、256 维、2 heads、FFN300、两步额外推理，history20；batch512、Adam LR0.001、grad clip1；前两轮关闭噪声。最多 300 轮，100 轮起启用平台判断，每 5 轮验证，patience10、min_delta0.0001。最佳 checkpoint 按实际最高趋势 NDCG@10 选择。

Beauty 使用完整 131,413 条训练前缀、固定 2,000 用户选模子集，最终评估全部 22,363 用户。全 catalog 打分后取 top50，PAD 不进入 softmax；GRAM 使用保存的 beam50 输出。比较使用相同验证用户和指标，但推理成本与模型结构并不匹配。ReaRec + PCRF 的重新组合没有评估；表内 PCRF 是历史 **GRAM + PCRF**。
