## 四、技术分析

### 4.1 MLP Bridge 训练情况
- **训练轮数**: 200 epochs
- **收敛状态**: 最终 val_avg_acc ≈ 0.261，训练 loss 收敛至 1.70
- **7-level 分层精度**: L1(84.4%) → L2(42.4%) → L3(19.7%) → ... → L7(7.3%)
- **符合预期**: 浅层高精度（语义粗分类），深层渐低（细粒度区分难度大）

### 4.2 为何 Beauty 提升低于 Toys？

可能原因分析：
1. **基线性能差异**: Beauty v0 cold hit@10 仅 0.306%，Toys 为 0.608%
   - 更低的基线意味着原始语义信号更弱，MLP 映射难度更大
2. **域特性**: Beauty 商品描述可能更主观（"elegant", "gorgeous"），Toys 更具体（"LEGO", "age 3+"）
   - 抽象语义特征更难映射到离散 ID 空间
3. **数据集规模**: 两域 cold item 数量相近（Beauty 6052, Toys 5963），但可能训练集密度不同

### 4.3 核心机制验证
✅ **已验证假设**:
- 文本语义可通过 MLP 映射到分层 ID 空间
- 映射后的 pseudo-ID 能显著提升 cold item 检索效果
- 方法无需域特定设计，跨域稳健
