## 固定时点和信息边界

在同一原生GRAM beam50上，分别记录第2、第3次词元扩展的**剪枝前**状态。重跑只生成3个词元；最大长度4包含decoder start，EOS最早出现在6/8次扩展后。先核验forced_eos为空，且3位训练用户的截断轨迹与完整生成前3步逐值一致；完整生成候选/分数与原缓存逐值一致。不启用曾破坏精确复现的cross-attention cache reuse。

四个量替换原四个晚期槽：

1. 当前候选前缀累计原生log分数 / 已扩展词元数；
2. 同一前缀按原固定alpha=.3、保留合法总质量规则计算的累计更新 / 已扩展词元数；
3. 该前缀在**本次所有活跃父前缀的合法扩展**中的原生倒数名次；分数并列按词元前缀字典序；
4. 该前缀混合累计分数距上述扩展的混合第50名边界 / 已扩展词元数；不足50取末名。

分母仅用当前长度，不能用完整商品路径长度。候选竞争集合取当下全部合法扩展，不可从最终50条路径反推。排除初始-1e9填充beam；同前缀去重。专家分支概率来自全目录预先可得的LIME分数。先算全部当前扩展的特征映射，再在结束后关联原冻结商品候选；特征生成函数没有目标或未来候选输入。候选对应的当前前缀未访问则报错，不允许教师强制补造活跃状态。

两时点明确是预先固定的探索对照，两者全报。GRAM候选、整条路径底分、商品专家分数仍用于最终的同候选排序检查；因此候选支持域和排序损失依然是生成后的。本轮不能检验目标剪枝救回，也不能将原生轨迹上有效直接推广到引导轨迹。

## 判定与停止

每个时点分别沿用此前门槛：两域开发NDCG@10都至少相对高于GRAM及fixed_late 1%，HR@10不降；两域OOF高于两基线且各至少4/5折同向；同一时点三个seed均通过才值得后续生成机制验证。报告对同seed early/full的差值、全部三seed、各折、两域、两集合及配对用户bootstrap区间（1000次、seed20260922）。这只是投入规则，不是显著性检验。

若两时点均失败，不在本轮继续改权重/专家/训练预算，不自动上线控制器。若通过，也只说明当前信息有价值；仍需真正改变beam和同信号后重排对照，不能直接宣布创新成立。
