# 候选补漏与排序保持：首轮匹配训练协议

Origin Skill: academic-research-suite。日期：2026-09-20。状态：设计冻结，首轮探索性筛查；非确认性验证、非已确立新方法。用户已授权开始下一步，实现、检查和运行本轮小实验。

## 问题与机制边界

假设：普通并集训练未充分处理两类跨来源竞争。GRAM已覆盖正确商品时，新增错误候选会挤掉它；只有LIME覆盖正确商品时，原GRAM候选可能阻挡它。对这两类训练样本增加跨来源排序约束，能否超过同输入、同容量、同预算的普通训练？

旧BW3门控在独立验证中没有准入任何正确目标；旧36特征门控也未支持可识别性。新实验使用独立LIME候选源，直接更新整个并集的排序分数，训练覆盖和补漏两类样本，没有硬准入阈值、最多准入3个或旧共同item-head分数锚。上述差异只说明实验并非原配方重跑，不自动证明新颖性。该损失可解释为按来源选择难负例的普通成对学习；必须用匹配控制排除这种解释。

## 数据与信息边界

- 冻结C1的既有训练候选缓存，以及LIME的SASRec seed0、ItemCF、BGE和仅cal2048用户拟合的融合器。seed0预先指定，不比较后挑最好种子。
- 使用gacr_fusion_train_v1的全部fit训练前缀，包含原生成未覆盖样本；排除本轮2048校准用户。逐行核对train_index、user、history和target，完整历史仅取该训练位置之前的序列。训练target只作标签，不注入候选。
- 不使用五折LIME融合器：跨折预测缓存用于再次训练会产生间接监督依赖。本轮所有样本统一使用仅cal2048拟合的同一个冻结融合器。
- 训练：原GRAM50与新LIME50去重并集，最多100个，统一排除最近20个历史商品。正确目标不在并集的样本不产生监督梯度，数量完整报告。对已覆盖训练样本按用户等权；所有训练臂权重、顺序相同。
- 评估：原固定评价用户Toys17364、Beauty20315；全部保留，包括两路均未覆盖用户。校准用户不参加评估。只用开发数据；test/Sports不读取。开发集已反复使用，本轮不能称为独立确认。
- 上游模型已学习全体训练事件，因此历史训练前缀分数属于训练内表示，不声称时间外推无泄漏的训练特征。评价目标不进入任何新模型拟合。所有训练臂共享此边界。

## 三项匹配训练

共同分数为20×LIME分数加同一个32维MLP的有界残差（±2）；最后一层零初始化。输入为三个专家归一化分数、LIME分数、两个来源标记、GRAM候选倒数名次、相对GRAM第10分数的差、训练频次及历史长度，共10维。标准化统计只来自训练候选。来源标记在所有臂均可见。

1. ordinary_ce：普通并集列表交叉熵。
2. hard_negative：相同CE，加0.25×成对softplus损失。按冻结LIME分数选最难负例，不限制来源。
3. cross_source：相同CE及损失系数，但GRAM已覆盖目标时只选外部负例；目标仅在LIME时只选GRAM负例。最多5个。hard_negative逐样本选取同样数量，候选选择在训练前冻结。

公式：L = CE(s,y) + 0.25×mean_{j∈N(u,y)} softplus(s_j−s_y)。ordinary_ce无第二项。空负例集合第二项为0。覆盖分组只用于训练损失，不作为预测输入。

三个小头初始化20260920/21/22；每臂30次完整训练集梯度更新；AdamW lr0.01、weight_decay0.001；chunk128仅用于等价梯度累积。不得根据开发结果选epoch、改权重或重跑后覆盖本轮。

## 固定对照、结果与继续条件

固定对照包括同cal2048 LIME完整目录、LIME评分＋GRAM50、LIME评分＋去重并集；报告旧完整A三个头和原crossfit LIME＋GRAM50 seed0作外部效果参照，明确监督不同。跨来源臂与普通/难负例臂拥有完全相同的候选规模，因此它们的差异不来自额外候选预算。

报告双域全体/低频/其他、GRAM覆盖/仅LIME覆盖/均未覆盖的N10、H10、H50，新增与丢失Top10，三种子全部结果，配对用户bootstrap描述区间。不得把oracle覆盖作为可取得效果，不从反复开发得出显著性或因果声明。

只有以下条件均满足才建议扩大：双域平均N10分别超过ordinary_ce、hard_negative以及同cal2048 G50至少0.5%相对值；跨来源相对两个训练控制在三个头种子方向一致；全体H10不低于同cal2048 G50，低频H10下降不超过0.001绝对值；平均N10超过旧A均值与原crossfit G50 seed0外部参照。0.5%和0.001是投入筛查阈值，不是显著性标准。失败则停止扩大这一具体损失配方，保留全部结果，不自动换参数。

## 工程和运行

CPU四线程，双域顺序执行；复用BGE编码和SASRec权重，无新上游训练或beam生成。准备前对128条训练前缀做前向profile，实测热身后约0.13秒/128条，完整耗时待训练profile估计。后台进程记录PID、阶段/进度/时间和日志，硬上限60分钟。检查目标不进入候选构造、两臂负例数相等、训练梯度方向、chunk梯度等价、历史掩码与同分item ID规则、原评估分数复现、保存checkpoint重放、输入输出SHA。
