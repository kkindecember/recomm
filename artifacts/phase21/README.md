# 第21阶段产物归档

2026-10-16更新归档。此目录采用[显式保留清单](.gitignore)：默认忽略生成产物，仅保留已检查的固定配置、协议、来源哈希、聚合结果、轻量实现检查、独立复核记录和必要人工审查标注。报告入口见[第21阶段索引](../../report/第二十一阶段/README.md)。

本次补充Qwen与TiSASRec专家替换、联合融合、生成决策与历史质量特征对照的协议、配置、汇总和复核哈希，以及历史过滤审计汇总。Qwen只保留环境与固定版本哈希清单；联合融合额外保留资源接续的有效配置和授权说明。下载元数据、重复汇总副本、逐用户检查记录、临时交接与失败日志继续留在本机。

模型权重及其临时文件、NumPy数组、全量商品或用户数据、逐用户预测、运行状态、日志、显存租约、重复源码和数据副本均不上传。被忽略的文件仍保留在本机；Git归档不等于完整实验数据备份。

复现时需另外准备原始数据、上游模型与派生缓存，按各实验协议和清单核对来源哈希；配置中的绝对路径对应原实验机器。外部代码按[第三方固定版本说明](../../third_party/README.md)恢复。

汇总文件可能包含已完成子组的部分结果，不能仅因存在 `summary.json` 就视为整批完成。例如原 `candidate_gate_controls_20261010_v1` 由后续恢复目录补齐，`candidate_gate_generation_resume_20261014_v1` 和 `expert_feedback_20260924_v1` 保留用户暂停凭据。完整结论以对应日期的报告、协议及核验结果为准；`status.json` 留在本机，不代表远端实时状态。

新增结果需检查后逐文件加入此目录的 `.gitignore` 保留清单。保留的人工审查标注属于研究证据，不是全量用户行为数据。
