# 单融合器全目录双专家探索

Origin Skill: academic-research-suite / experiment-agent，内联执行。用户明确要求将“一个融合器直接合成两个专家，再引导GRAM”改成实验；本计划及代码实现、后台运行均属于本轮授权。

## 问题与结构

21.23的残差候选权重在真实生成N10中没有优于用户级对照。本轮测试简化后的独立融合器，替代旧融合器加修正小头。固定SASRec＋BGE，不使用ItemCF；保留同一GRAM及原概率引导规则。

唯一可训练模块为16→32→2 MLP，softmax输出双专家权重。所有目录商品均由该融合器计算 `f(u,i)=w_S(u,i)*s_S(u,i)+w_T(u,i)*s_T(u,i)`。无旧融合分数、旧权重、旧门控历史惩罚、残差加分、top150修改集合或集合外回退。重复历史只作为可观测特征；最终排名沿用最近20历史过滤。专家原分数、频率、历史等为只读缓存，专家及GRAM均冻结。

三组同流程对照：mean（双专家各0.5），user（每用户一组权重，覆盖全目录），candidate（每用户每商品一组权重，覆盖全目录）。user/candidate使用相同网络名义参数量，user不激活商品特征分支。用户特征10项为历史长度、两个专家的最高分相对均值／前两名差距／分数标准差／前五历史占比，以及目录历史占比。商品特征6项为两个专家分数、两个专家全目录倒数排名、训练频率log1p、是否出现在该用户真实历史。特征函数不接收目标标签。旧融合器只作为外部结果对照，不参与新模型特征、目标、初始化或损失。

本轮同时改变了旧锚点、候选范围和特征，属于新简化方案的整体探索，不把与21.23的差值解释为任何单一改动的因果效果。旧compact实验双专家训练未完成，且存在候选外均值回退，不混用其结果。

## 训练与验证

固定seed0；仅使用既定ranker_fit用户，Toys2773、Beauty3310。按既有用户hash五折选一折内部留出，训练最多20轮，在0/4/8/12/20轮以内部留出全目录CE选择轮数；从同一初始化重新在全部ranker_fit拟合所选轮数。输入标准化分别只用选择拟合部分／最终全部拟合用户统计。AdamW lr=.002、wd=.001、batch32；精确全目录交叉熵 `CE(20*f, target)`，无旧分布KL约束，不采样或注入目标候选。

全目录训练与推断以批次计算，计算分块不限制推荐范围。当前目标是验证结构可行性，固定一个小头seed，不进行扫参或完整论文实验。

训练结束后，无论纯专家排序优劣，都在21.23相同每域512开发用户执行mean/user/candidate真实生成。上一轮已经说明纯排序优势不能代替生成效果，故不按纯排序数值选择是否生成或选择最佳变体。验证用户与所有本次拟合用户不交叠。该512用户重复用于探索，不是独立确认集。不读test。

保留原GRAM、原双专家、三专家及21.23候选修正的同批结果作为参照；GRAM逐用户重新生成并校验，旧双专家在3位用户上重放校验。新三组每用户同时保存原生50候选同规则后重排和真实引导生成。alpha=.3、score_scale=20、beam50、length_penalty=1，沿用固定全目录标识树、合法概率质量保留及历史过滤。全目录专家信号在一次用户生成中固定，不更新GRAM参数。

主报告为逐域NDCG@10及候选／用户融合分别相对GRAM、旧双专家、均值融合，以及候选相对用户级的变化。H10/H50、命中人数和配对描述性区间同时完整报告。不能只选表现最佳域／变体，不能因超过GRAM就断言新融合器必要。若mean已相当，明确保留更简单平均方案的可能性。现有专家消融不证明新融合器下两专家都必要，本轮不扩充完整专家消融矩阵。

## 执行和审计

两域最多并行2任务，动态扫描全部GPU，每任务入场要求空闲至少32768 MiB；总租约30720 MiB，保守工作负载峰值12288 MiB，侧车18432 MiB，主程序11 GiB分配上限。GPU训练和解码在同一租约下用两个子进程顺序执行，训练进程退出释放缓存后才加载GRAM。每域超时6小时，资源等待最多24小时；失败保留状态和日志，不自动重跑科学任务。所有超过10分钟的工作由tmux后台监督，status每10秒刷新，拟合每轮、解码每8用户更新子状态。

预计共享机器上训练加真实生成约1–2小时，实际以状态文件中的耗时与生成进度估计为准。只短查启动和正常进展，不持续监看完成。

验证包括：全目录候选权重与用户共享权重性质；均值初始化；分数凸组合界限；不存在top150回退；去掉ItemCF不影响输入；目标不进入特征；CPU NumPy独立前向；批次和逐用户分数一致；选择／拟合与开发用户分离；旧GRAM及双专家重放；保存后重读预测重算指标；输入、模型和源代码哈希。
