# SASRec 与 TiSASRec 并行对照

用户授权：与已启动的 Qwen 文本替换任务并行比较 SASRec 和 TiSASRec；长实验后台运行，由 artifacts/status 文件观察。当前属于方法探索，不启动整套论文实验。

## 问题与三组

1. `full`：现有 SASRec + BGE + 用户级单融合器。重用已核验模型与分数，并完整重放 512 用户生成。
2. `tisas`：TiSASRec + 同一 BGE + 同结构重新训练的用户融合器。
3. `tisas_order`：与 tisas 完全相同的模型/参数量/初始化种子/训练批次，但把每次交互日期换成等间隔位置。保留额外相对位置建模能力，完全移除真实时间信息。

先比较 2 与 1 判断实用替换价值，再比较 2 与 3 判断真实时间是否有额外价值。不能把 TiSASRec 与现有 SASRec 的所有架构差异解释为时间收益。

## 固定条件

- Toys、Beauty 各沿用当前 512 名开发用户。它们已经反复用于探索，不代表独立验证集；本轮不使用 test 指标或目标时间。
- 与现有 SASRec 一致的冻结上游训练序列、catalog、最大长度50、hidden64、2层/2头、dropout0.2、seed0、batch128、Adam lr0.001/weight_decay0、clip1、全目录CE/label smoothing0.1、固定200轮，无验证选轮次。
- 上游训练先移除每个用户的训练末件商品；融合器使用原有 ranker_fit 用户（Toys2773/Beauty3310），与评估用户互斥。每个新行为模型独立按原内部80/20划分选融合器轮次，再 refit；不根据512效果选轮次。
- 原 SASRec 为 legacy 实现、CPU训练；TiSASRec为GPU训练、独立时间注意力实现。并非等参数架构消融，不声称逐位相同的数值训练过程。
- BGE分数逐项不变。GRAM checkpoint、原 SASRec 相似商品提示、商品ID树、alpha0.3、score_scale20、beam50、历史过滤和排名并列规则不变。
- 保存行为模型单独排名、融合专家排名、同原生候选重排、完整引导生成。所有预定模型均生成，不用中间开发指标筛选保留组。

## TiSASRec 实现与时间边界

来源：[Li et al., WSDM 2020](https://doi.org/10.1145/3336191.3371786)、[作者 TensorFlow 实现](https://github.com/JiachengLi1995/TiSASRec)、[作者链接的 PyTorch 实现](https://github.com/pmixer/TiSASRec.pytorch)。本地实现同时加入相对时间的 key/value 向量与绝对位置 key/value 向量，并使用论文的归一化/残差/逐点前馈结构。保留本项目全目录CE训练协议，不声称原论文结果复现。

公开数据 unixReviewTime 是评论日期，精度为天，不能写作精确购买/点击时间。按现有 user/item ID 对齐，不重排同日事件。只保留上游训练及本轮可见历史的日期；预测目标日期不进入模型输入。

与公开代码有意不同：每个 query 的最小非零间隔只从其可见前缀求得，而非读取完整用户序列后统一归一化。以当前截断窗口首个可见事件为原点，分别对前缀内各日期除以上述尺度并四舍五入，再求相对差并截断到256；无正间隔时尺度取1。不同 query 可以使用不同尺度。未来 key 独立被因果遮罩屏蔽。此因果版不与公开全序列归一化结果混称。

等间隔对照用事件位置代替真实日期；不是随机打乱日期，不破坏商品顺序，也不让模型读取目标时间。两种TiSAS同seed、同模型、同batch序列、同训练预算。

## 运行与检查

- 独立 tmux，两个域最多并行两张卡，动态挑选空闲显存≥32768MiB的GPU。
- 遵守项目30GiB租约；预计workload峰值12288MiB，sidecar保留18432MiB，进程allocator上限11GiB。
- 单域6小时上限、资源等待24小时；每轮和训练中间batch更新status，生成每8用户更新；完成/失败释放租约，不自动科学重试。
- CPU检查独立标量注意力公式、未来日期/商品变化不影响前缀输出、日期平移不变、等间隔组不读取日期、有限梯度、时间key/value均参与反向、padding；原训练序列/模型/数据哈希锁定。
- 每个新融合器独立NumPy重算；GRAM alpha0一致、旧SAS+BGE完整512回放、结束模型digest不变、保存预测独立排序复核。
- 现有归一化和历史聚合来源包含LIME-Rec，沿用的概率引导包含AGRec启发；本轮不通过更换专家宣称这些机制首创。

## 判断边界

首要指标完整引导NDCG@10，兼报H@10/H@20/NDCG@20、原生GRAM、配对收益/误伤。若两域均优于当前SAS并优于等间隔对照，才支持继续把真实时间作为替换动机；单域或微小不稳定收益不强行统一解释。

一个seed和重复开发用户只支持探索性选择，区间为描述性未校正区间。当前任务结束后不自动与Qwen组合，也不启动多seed/全量/test/学习alpha。
