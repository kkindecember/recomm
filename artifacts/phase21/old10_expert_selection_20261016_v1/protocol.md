# 固定原十维筛选专家的真实生成对照

## Material Passport

- Origin Skill: academic-research-suite / experiment-agent，内联执行
- Origin Mode: run
- Origin Date: 2026-10-16
- Verification Status: PLANNED
- Version Label: old10_expert_selection_v1

用户明确要求先使用最初10维融合器确定专家，再研究融合器。本轮冻结原10维定义、32隐藏单元、用户级beta/alpha联合头（451参数）、CE父模型和GRAM目标路径NLL适配流程。仅专家输入发生变化，不加入六维/七维输入，不加入去自匹配、均匀历史降分或新的历史惩罚，不重训GRAM或专家，不读取test。

## 比较范围

行为位置：SASRec、TiSASRec、ItemCF；内容位置：BGE、Qwen3-Embedding-4B。六种配对全部生成，不能由单专家直接排序淘汰候选。

五个单专家对照也参与同预算的用户级alpha适配。为保留相同10维定义和451参数结构，同一专家的分数送入原两个槽；两槽beta无论如何分配都只产生该专家的分数，没有残留被移除专家的评分或特征。此时CE与beta无关，CE父阶段采用数学上等价的零步初始化，避免为数值噪声挑选CE轮数；NLL仍按相同内部划分、轮数和损失学习alpha。单专家对照说明在该固定融合方案下另一个专家是否有增量帮助，不保证适用于所有融合器。

原10维来自当前LIME衍生特征：log历史长度、两项最高分减均值、两项Top1减Top2、两项分数标准差、两项Top5历史重合、历史商品占比。完整可见历史范围、Top5和分数尺度均不改。特征名称仅将sas/text改称slot0/slot1以支持候选替换，不改变数值公式。

三专家不能在保持原10维、两输出beta完全不变时直接加入；本轮ItemCF作为行为位候选，不声称已经完成三专家组合消融。旧三专家全量结果作为历史参考，保留它的历史惩罚说明，不当作本轮匹配三专家结果。

## 训练与复用

拟合事件沿用Toys2773、Beauty3310。内部user-hash80/20，seed0、AdamW lr.002/wd.001、batch32、检查点0/4/8/12/20。标准化仅来自当次拟合子集；选择后全拟合重训。

SASRec+BGE、SASRec+Qwen4、TiSASRec+BGE的既有原10维联合用户头直接复用。须逐条核验训练用户、原10维输入、标准化、权重和旧512导出评分/alpha/beta，并对少量真实生成重放。其他三组用相同CE→NLL规则新拟合。CE折内父模型只用内部训练用户，NLL折内不接触内部留出标签梯度。复用头沿用其既有CE轮数选择，这是原方法的历史训练待遇，不将其声称为新训练复现。

冻结GRAM真实路径native/legal缓存复用且核验用户、目标顺序与摘要。目标只用于损失与评估，不参与专家选择名单、特征或推断输入。

## 验证人群与指标

名单完全沿用21.42：原512与新增4096不重叠，每域4608。4096排除早期融合拟合/校准用户；两组均为已接触过的validation，非独立test。原512用于历史衔接；4096作为本轮主要开发比较，分组报告、不按结果混合挑选用户。

每组运行全目录专家分数引导的真实beam50生成，所有生成前缀继续引导。最终排序不排除历史；N/H@5/10/20/50按相同ID打破并列。GRAM基线复用同用户的既有原始预测，并在每个分组首/中/末检查新模型解码一致性；复用头旧512预测也须真实重放检查后使用。其他用户/组合重新生成。每个用户记录哪些结果复用、哪些新生成，不以是否命中决定复用。

报告每个配对相对GRAM、相对其两个单专家的配对差值。双域均受益和另一专家可替代性共同影响暂定选择；不靠非零权重证明专家有用。CI为固定模型下2000次用户bootstrap的未校正描述区间，不能称为最终多种子独立测试结论。

## 实现核验

优化的统计拼装须对原C.features逐位一致；三个旧配对在全部拟合行、原512行与既有特征逐位相同。单专家同槽分数严格不依赖beta；NumPy独立前向复核全部beta/alpha与评分。合法目录不变、alpha0与原生入口完全一致、推断目标占位替换不改变编码输入；全目录分数有限、权重归一化、模型摘要不变。来源及输出清单、协议与代码快照保存，不覆盖旧实验。

## 后台与资源

tmux后台、两域并行、每域最多一个GPU；全GPU按利用率低、空闲显存多选择，避免仅盯预定卡。沿用用户降低显存预留的要求：总预算16GiB，工作峰值12GiB、侧车4GiB，启动要求18GiB，模型分配上限11GiB。仅空闲不足的资源入场可重排，科学失败不自动重试。

每域12小时硬超时，资源等待24小时；状态每10秒汇总，生成每8用户更新剩余时间估计。预计数小时，实际受共享GPU计算负载影响。完成本轮专家比较后停止，不自动改融合器或启动整套论文实验。
