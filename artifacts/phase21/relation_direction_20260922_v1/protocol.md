## 候选卡 A：有方向的局部关系证据，本轮执行

**缺口。** 原 ItemCF 已有 top100 加权邻居和最近20项线性近期加权（代码 `third_party/LIME-Rec/lime_rec/experts.py`），不能把权重或近期加权重新命名为专家。待验证增量是局部购买顺序的方向。共购不是因果互补关系；时间顺序也不是因果。

**相对旧实验。** 第7阶段已经训练过深层 transition/session-GRU 并失败于固定 token 融合；本轮不重复该模型，也不把简单方向统计当作论文创新。先用冻结干净上游、可解释的前向/无向/反向对照，确定方向证据在当前系统中是否仍有独立价值。第20阶段 early 校准的失败说明只增加可生成前取得的分数并不保证改善。

**数据。** 两域 `upstream_sequences_without_terminal.jsonl`；核验原 receipt 哈希、商品频次及每个评价用户的历史等于该用户允许序列。图构建只接收这些序列，不接受留出目标。复用 clean-benefit 的原候选、固定引导候选和专家分数；不读取 test，不改变已完成实验。

**证据定义。** 对每个允许序列，间隔1、2、3的前向非自身商品对累加 `1/间隔`；这是事件计数，不是独立用户支持数。前向 F，反向 Fᵀ，无向 F+Fᵀ；各自按 `边权/sqrt(源出强度×目标入强度)` 归一化，每源保留100邻居，按商品ID打破平局。最近20项历史用与已有 ItemCF 相同的线性近期权重聚合。额外消融为同一前向邻居集合的二值边、前向加权边的均匀历史聚合。没有权重/窗口搜索。

**第一层：全目录机会检查。** 全部 ranker_fit 与 development 用户；报告各信号 N10/H10/H50、正分数覆盖、原 GRAM50 与引导50及三个专家/LIME top50 的遗漏救回数。图 top50 只保留正分数合法商品，避免零分平局造出假覆盖。新增候选是机会而非可实现生成收益。另报告 GRAM25+关系25 与 GRAM25+ItemCF25 的等上限预算覆盖；并集 oracle 不写成方法成绩。

**第二层：同候选、同校准器的价值检查。** 复用原生50候选和10维 full 信息，底分 `10×mixed`。固定线性残差 `底分+标准化特征·w`，正则 `0.01×||w||²/2`，SciPy L-BFGS-B，最多200迭代，gtol=1e-6。训练仅合法候选覆盖的正例；评价所有用户。标准化只取当前训练折。6个固定臂：base；base+无向近期；base+反向近期；base+前向二值近期；base+前向加权均匀；**base+前向加权近期（唯一主臂）**。新增关系通道按请求最大值归一化。五折按旧 clean-benefit 用户哈希划分；最终头只用全部 ranker_fit，开发标签只评价。所有臂和失败均保留，不按开发结果选臂。

**主要指标及决策。** 推荐 NDCG@10；同时检查 H10、新增/丢失命中、训练OOF方向、CPU时间与内存。进入生成接口验证需唯一主臂在两域开发 N10 均比 base、无向、反向三个对照各高至少1%，相对 base 的 H10 不降；两域 OOF N10 胜过三个对照且至少4/5折同时胜过；开发中每域至少新增3个不在 GRAM50、引导50、三专家top50和LIMEtop50内的目标机会。1%和3例为投入筛查规则，不是显著性阈值。报告固定预测的用户bootstrap描述性95%区间，不宣称确认性显著。

未过门槛：区分“无额外覆盖”“有覆盖但现有排序器用不好”“普通无向证据已解释”；不扩大方向图容量/窗口搜索。单域成功只记单域信号。此门槛约束当前有向统计实现，不否定所有结构化关系表示。

**至多两个后续位置。** 有强证据才考虑：(1) 历史商品编码侧读取少量有向邻居证据；(2) 解码器在当前前缀下读取商品级关系记忆。均需与相同证据的普通固定引导和后重排比较；大训练不能省略零初始化/无证据对照、同训练预算、跨域与训练随机性验证。

## 候选卡 B：同128词元的属性保留，本轮不训练

**依据。** 21.0 抽查中 Beauty 描述标记仅14/128保留；这只是输入损失证据。缺口是被截断的属性，不是“GRAM没有语义”。

**最简单对照。** 相同128词元、相同文本源、相同邻居数，比较原排列与字段配额保留；先核验实际词元和各字段保留，不引入外部文本。推理时直接换输入会有分布失配，只可作零训练探针；正式净收益需要原排列/新排列从同一初始化、同一更新预算训练。先看这个简单对照，再决定是否值得建立属性专家。

**至多两个位置。** 商品编码的字段保留；解码器读取按历史选择的属性片段。若收益已由输入保留解释，记录为输入改进，不强行包装专家。

## 资源与执行

CPU 2线程，两个域顺序运行，不占GPU；预估5–20分钟（执行后以实测修正），硬超时45分钟，缓存预算小于2GB。以后台监督器启动，30秒心跳，保存PID、阶段、完成进度、更新时间、失败原因，自动完成摘要和报告。上游训练0次，本轮不是生成实验。超过预算结束本任务子进程，不触碰其他任务。

已有开发池多次被研究；五折共享冻结上游，bootstrap不包含上游随机性/研究选择不确定性。后续新生成的成功必须另有独立确认，不能把本轮称为泛化验证。
