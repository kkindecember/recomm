# 21.19 候选级权重与历史依据匹配试验

2026-10-10；用户明确授权检验两个假设。Origin Skill: academic-research-suite。
本文件在新实验指标产生前固定。沿用项目的仓库计划/报告格式，不创建外部页面。

## 问题和边界

H1：同一用户对不同候选使用不同专家权重，能否超过同数据训练的用户级权重？
H2：真实历史评分贡献的结构，能否超过候选分数本身以及打乱历史的对照？
先检验冻结专家的全目录商品排序；这不等价于生成效果。只有稳定的双域增量才考虑追加真实生成验证。
候选门控首先解决融合层问题。另从已有完整生成输出核算 GRAM 候选缺失与排序问题，不能用门控假设冒充 GRAM 已证实缺陷。

## 固定数据和模型

训练使用 clean_benefit 的 ranker_fit：Toys 2773、Beauty 3310 个训练末次留出事件。
从用户 ID 的固定哈希划分 20% 内部留出，选择训练轮数；之后使用全部 ranker_fit 重拟合。
冻结 GRAM、专家分数、原门控、历史惩罚；不读取 test。
评价使用已有完整 validation 缓存，同时单列与所有门控拟合用户不重叠且不属于旧 512 用户的 primary 群体（15406/17766）。这些 validation 已用于历史探索，不能宣称全新确认集。

候选 C 为排除最近 20 件历史后三专家 Top50 与原融合 Top50 并集；按商品 ID 处理并列。候选选择和所有特征不接收目标。集合外分数不动，不强行插入目标，不删除集合外目标用户。
文本贡献精确沿用原始 BGE 历史向量、exp(-0.1 age) 池化及其归一化；CF 贡献沿用最近20件的线性位置权重及训练共现邻居。统计绝对支持、集中度、近期占比、正负贡献、相对原融合第10名的分差抵消；不使用品牌规则或生成语言解释。

## 对照

- A：冻结原融合。
- B / user：原用户统计输入的小网络，对 C 内所有候选共享同一个新权重；C 外不动，与 C/D/E 的修改范围相同。
- C / score：候选分数、名次、边界分差，加相同用户统计。
- D / evidence：C 加真实历史贡献结构。
- E / shuffled：与 D 同结构，历史从同划分、相近长度的另一用户取得；独立训练。
- G / global：与 B 同输入，但新用户权重作用于完整目录，额外排除 B 修改范围带来的局限。

所有新头均为统一输入宽度（缺失特征置零）、32隐单元 ReLU、3输出；输出层全零初始化。记录实际活跃输入数量和参数量，不声称信息容量完全相同。
有界校准 w=(1-eta)w0+eta*softmax(log(w0)+g)，eta=0.1；使用增量写回保证零修正/eta=0返回原始分数。
损失为全目录 CE(20*S)+0.2 KL(P0||P)，集合外概率质量精确计入。G 用完整目录直接计算。
AdamW lr=0.002, weight_decay=0.001, batch_size=64，最多20轮；头种子0/1/2。内部分割固定跨种子，选轮候选0/4/8/12/20，以内部留出损失最小选轮，同分取较早轮。标准化只用相应训练子集。所有最终模型在选定轮数后停止，不按外部 validation 选种子/轮数。

## 判据和运行

两域全量及 primary 均报告 NDCG@10、Hit@10、Hit@50、按种子结果、用户配对差值及95% bootstrap区间；三个头种子不是三个独立上游种子。primary 为主判断，全部用户作敏感性分析。
H1主要比较 C-B，同时参考 C-A、C-G；H2比较 D-C 和 D-E。仅单域或单种子正结果不算稳定双域支持。
若 D 不胜 C，则不将“历史依据有效”写成已验证贡献；若 C 不胜用户级对照，则本轮配方不支持 H1，不继续盲目扩大生成预算。这不排除其他候选门控设计。
本轮 CPU 执行，线程上限4；运行上限4小时，保留状态、时间、源码快照、配置与输入哈希。完成必要正确性检查后才训练。无 GPU、无新骨干训练。

检查：零修正与集合外不变；压缩全目录损失/梯度对照直接计算；真实贡献与独立逐事件求和一致；排序计数与独立排序一致；用户分割不重叠；目标不进入特征；打乱对照确实更换用户；原缓存哈希验证。结果是本机数值复核，不能称独立团队复现。

同时审查：实验单位为用户，领域分开，不按目标入候选条件筛出主结果；所有失败与所有种子保留；多轮历史探索与选择偏差披露；不把支持相关性写成因果；validation 不参与新头拟合，历史只用观测时间前信息；未知效果不赋予伪造的成功概率。
