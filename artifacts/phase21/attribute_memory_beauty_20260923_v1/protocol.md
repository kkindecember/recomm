# 21.2B 原输入保留的描述记忆实验

日期：2026-09-23。Origin Skill：academic-research-suite。用户已授权继续寻找有效方法。本协议在新方案训练与开发评价前冻结；仅Beauty单域探索。

## 假设和区别

21.1B将协同邻居由10减到2以保留描述，真实描述布局已完成的N10低于原布局。该结果同时涉及信息取舍和全模型适配。本轮检验：保留原128词元输入和全部10个邻居、冻结原骨干，通过独立描述记忆和小型解码状态残差能否取得增量。不能预设上一轮下降由删邻居造成。

原干净GRAM30为骨干，用户/商品输入、合法生成路径和原评分保留。对每个目录商品使用同一冻结骨干的文本编码器，把最长64词元的描述编码成一个masked-mean向量，作为历史商品记忆；包含EOS。它是描述的首段，不保证全部是原输入从未出现的内容。缺失描述对应零记忆且被屏蔽。新输入预算最多每历史商品额外64词元；编码离线缓存并计入成本，不冒称同128词元预算。

每次生成的当前解码状态查询历史记忆。单头query/key/value投影至64维，输出回512维；输出投影零初始化，残差tanh限幅并按T5输出尺度缩放。只影响语言模型输出投影的输入，不改原骨干中间状态或KV缓存。所有131072个支路参数可训练，原骨干冻结、eval模式，不使用其dropout。

## 固定比较

| 组 | 信息 | 作用 |
|---|---|---|
| parent | 原GRAM，无新增支路 | 原系统基线；复用同1024人已完成预测，先做3例逐路径/分数一致性检查 |
| seen | 支路读取原128词元中已可见的前段 | 控制新增参数、容量与训练；词元长度和缺失位置与真实描述组逐项相同 |
| attribute | 支路读取真实商品描述首段 | 唯一主方案 |
| shuffled | 同长度桶内固定错配描述 | 控制描述与商品对应关系；其余同主方案 |

seen/attribute/shuffled三组相同初始化seed2023、相同完整训练顺序、相同参数和更新数。错配仅按商品ID哈希在相同长度桶中循环移位，不读取用户或目标；单例桶保持不变并记录。各组使用相同缺失掩码。真实描述效果不能只与错配比较。

## 训练与评价

复用原允许训练127328条记录、训练末次事件留出边界及Beauty固定1024人开发名单；不读test。每组完整一轮995次更新，batch16、累积8；AdamW lr=0.001、weight_decay=0.01，5% warmup后线性衰减，clip1。只用原下一商品词元CE，不追加排序蒸馏、偏好损失或超参搜索。

每组固定最终权重用真实合法beam50生成；排除最近20条历史，按分数/商品ID确定排序。记录合并1024人及existing512/additional512的N10/H10/H50、配对描述性95%区间、前十新增/丢失人数和成本。原系统的预测需逐用户重算；每组生成输出也独立重排复核。

投入条件：attribute合并N10相对parent及seen各至少+1%，H10均不降；两个512子组相对seen的N10均不降。描述对应支持另要求attribute相对shuffled合并N10为正且H10不降。未满足不自动增加轮数或更换学习率。仅一个骨干seed与一个支路seed，通过仅支持第二域和训练随机性复验。

本轮不包含LIME引导，不能仅胜过原GRAM就声称胜过当前专家系统。原512人另报告既有固定引导的匹配数值参照；若支路有净收益，下一项再比较支路+同一固定引导和原固定引导，并保留同信号后重排。新增1024评价不能与旧512指标混排。

## 运行、资源和工程边界

独立目录`artifacts/phase21/attribute_memory_beauty_20260923_v1`，不修改已冻结的GRAM/第20阶段代码；输入、代码和计划快照先存档。CPU2线程；GPU6按UUID绑定，启动需空闲至少16GiB，进程allocator上限12GiB；不干预其他任务或GPU7属性恢复。

先进行最长历史压力检查、3个普通更新计时、3例零支路真实beam与父缓存一致检查。试跑参数丢弃，各正式臂从同一零输出初始化重新开始。三臂训练加评价预估超过6.5小时则明确RESOURCE_BUDGET_STOP，不缩训练量。单任务7小时硬超时，仅终止本任务；每100更新保存支路/优化器检查点；异常保留、不按效果自动重试。

后台监督器每15秒给出阶段、进度、存活和耗时；最终自动独立重排、生成JSON和中文报告。数值正确性检查是同一助手的不同代码路径，不是外部审稿。开发池已多次使用，区间不覆盖训练随机性或研究选择，不作独立测试/确认性显著/购买因果声明。
