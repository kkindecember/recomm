# Toys/Beauty Non-Adaptive Validation Firewall

## Material Passport

- Origin Skill: academic-research-suite / experiment-agent
- Origin Mode: experiment governance
- Created: 2026-07-28
- User Decision: continue method innovation on Toys and Beauty
- Constraint: new methods must not be designed or tuned from Toys/Beauty validation outcomes
- Sports Status: sealed confirmation domain

## 1. Dataset roles

| Data slice | Allowed use | Forbidden use |
|---|---|---|
| Toys/Beauty training prefixes | mechanism diagnostics, fitting, shared hyperparameter calibration, power/resource estimates | reading `sequence[-2]`/`sequence[-1]` |
| Toys/Beauty validation | one-shot preregistered falsification and effect gate | post-hoc feature, loss, threshold, cohort, weight, seed or architecture redesign |
| Toys/Beauty test | frozen final evaluation only | direction selection, debugging, early stopping or rescue |
| Sports | final confirmation after method/config freeze | current direction generation |

## 2. Method-origin rule

Before any new validation run, the method hypothesis must be traceable to at least one source that
does not use the new Toys/Beauty validation outcome:

1. literature/theory argument;
2. training-prefix-only diagnostic;
3. implementation correctness requirement;
4. an external development domain.

Prior Toys/Beauty validation results may be cited as background or a falsification ledger, but a new
component cannot be justified solely as a repair for the latest validation failure.

## 3. Preregistration gate

Every direction must freeze before validation:

- research question and mechanism;
- exact train/calibration/validation split salts;
- allowed inputs and target/test exclusions;
- model structure, loss, optimizer, steps/epochs, seeds and shared hyperparameters;
- baselines, ablations, metrics, subgroup definitions and bootstrap unit;
- conjunctive pass/stop thresholds;
- code/config SHA and fixed conclusion space.

Correctness smoke and training-prefix premise audits may unlock a preregistered effect pilot, but
may not change its scientific thresholds after validation is read.

## 4. Validation-use rule

- One locked validation read per direction.
- Toys and Beauty remain conjunctive unless preregistered otherwise for a theory-based reason.
- A failed direction is closed; no bound/weight/feature/negative-quota/seed rescue on the same
  validation evidence.
- A successful direction is frozen before any test or Sports run.
- Dataset-level repeated adaptation remains a limitation and must be disclosed even when cohorts are
  user-disjoint.

## 5. Continuation rule

Continuing on Toys/Beauty is allowed. The next direction must first pass an independent
novelty/mechanism review and receive a fresh preregistration record. The Phase-4 evidence matrix
remains a negative-results ledger, not a menu for validation-driven patching.
